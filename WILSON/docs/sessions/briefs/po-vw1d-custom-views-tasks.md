## Facts that will bite

- Move the untracked `.claude/launch.json` at the worktree root to your scratchpad before the checkout; never delete it. `JSON.stringify` of the tracked one rewrites other sessions' escaped characters: insert as text. Its working copy is CRLF: anchor on the file's own line ending.
- **The provider already offers each view mutator's undo toast**: do not add a second; pass `{ words }` for the screen's own. None of them is a keyboard-history step (Ctrl+Z is not bound on Tasks).
- **A saved grouping whose set rows already have is that combination's group** (never two groups for one set), and it hides while one of its items is in the trash (`isGroupingLive`).
- **`ctx.tableViewLast.status` other than `ready`** (loading, unavailable, failed): open on *All* and write nothing for that visit. **`ctx.lastViewOf(tableKey)` can name a view deleted since** (by a teammate, on another computer): open on *All* when `viewsOf(tableKey)` no longer holds it (design §4.5).
- **The lane CSS guards are shared** (`rabbitCssGuards.js`; VW1b's hand-off): read them before touching a sheet. The kit takes additions only with a recorded kit request and a caller in the same commit.
- The desktop's page address changes at every launch (`listen(0)`): nothing about views lives in `localStorage` (the last used view is the machine's file on the desktop, VW1c).
- The Bash tool persists output over ~30 KB to a file; Bash heredocs halve `\\` (VW1c: a `\r\n` anchor became a real line break); the Write tool can turn an escaped surrogate pair (`\ud83d\ude00`) into the character itself (twice in VW1c, inside quoted strings), while a lone `\udc00` and `\u0000` stayed escaped: write such tests with the escape built at run time, or scan the bytes after writing.
