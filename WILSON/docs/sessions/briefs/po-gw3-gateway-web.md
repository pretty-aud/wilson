- **`npx vitest run` from `WILSON/gateway/` finds no files**; run from `WILSON/`. **A reviewer run in the main checkout sees no gateway** and reads "no test files" as a broken config: give it the worktree's path.

- **A `<video>` cannot read response headers**: the door is known from the address that answered the probe, not from `Wilson-Gateway-Path`; `/v1/path` is 404 on the outside door on purpose.
- **Ten failed tickets on one connection close it**; a stale ticket after a laptop's sleep must be replaced, not retried.
- **Tests that depend on luck** (GW2 trap 7): flip a bit of a decoded signature, never a base64 character.
- **The app's untracked `.claude/launch.json` at the worktree root blocks the checkout**: move it to your scratchpad, never delete it. **The Bash tool persists output over ~30 KB** to a file: read long documents in slices. **A `<!--` in a long markdown file is a silent delete**: count the markers after editing the design, OUTSTANDING or Help.
