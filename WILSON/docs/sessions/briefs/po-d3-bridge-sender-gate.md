## Facts that will bite

- Move the untracked `.claude/launch.json` at the worktree root to your scratchpad before the checkout; never delete it. `node_modules` is absent in a fresh worktree, and its install brings no Electron binary.
- **`wilson:local-server-token` is answered by `ipcMain.on` with `event.returnValue`**, synchronously, before the page's first script: a refused sender must still get a `returnValue` (null), or its page hangs; and `rendererOrigin` is set when the local server binds, before the window exists, so the gate reads it at call time, never at registration.
