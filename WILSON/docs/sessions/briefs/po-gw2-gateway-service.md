## The wire, fixed (the controller's, so GW1 and GW2 agree without talking; identical text in GW1's brief)

- **Enrolment token:** `wgt_` + 32 characters of base32 (RFC 4648 alphabet, upper case, 160 random bits). The cloud stores SHA-256 (hex) of the WHOLE string's UTF-8 bytes. 24 h, single use, spent by one `UPDATE … RETURNING`.
- **Gateway credential:** `wgc_` + base64url (no padding) of 32 random bytes; stored as SHA-256 (hex) of the whole string; carried as `Authorization: Bearer <credential>` on every gateway call.
- **Signing keys:** Ed25519 per workspace; `kid` is 1–16 characters of `[a-z0-9]`; the public half travels at sync as standard base64 of the raw 32 bytes: `signing_keys: [{ kid, public_key }]`; the previous key is accepted for ten minutes after a rotation.
- **The ticket:** claims object with keys in exactly this order and nothing else: `v` (the number 1), `kid`, `gw`, `ws`, `sub`, `clip`, `loc` (all ids lower-case UUID strings), `path` (the cloud's `relative_path`, forward slashes), `seq` (boolean), `mt` (the media type string the row holds; advisory), `rv` (boolean), `iat`, `exp` (integer Unix seconds; `exp = iat + 120`), `jti` (32 lower-case hex characters, 128 random bits). `payload` = base64url without padding of the UTF-8 bytes of `JSON.stringify(claims)` with no whitespace. `sig` = base64url without padding of the Ed25519 signature over the ASCII bytes of the string `v1.<payload>`. The ticket = `v1.<payload>.<sig>`. The gateway refuses a ticket string longer than 4096 characters before parsing; `iat` is the not-before; clock skew allowed: 30 s each way.
- **Renewal body:** `POST /v1/clips/<bin_file_id>/renew`, `Content-Type: application/json`, `{ "jti": "<the stream's first jti>", "t": "<the fresh ticket>" }` → 204 or 401.
- **The cloud's address:** the enrolment token carries no URL. The gateway takes it as `WILSON_CLOUD_URL` (container), as the installer's second field (an MSI property) and as `wilson-gateway enrol <token> --cloud <url>`; the compiled-in default is prod's functions base (`https://rqyriuyldhovirbuievt.supabase.co/functions/v1`); the health line and the status page say which cloud it talks to.
- **Test vectors:** GW1 commits `docs/design/gateway-ticket-vectors.json` (a fixture key pair, its `kid`, five tickets with verdicts) in its first commit. Before your review round 2: `git fetch origin po/gw1-gateway-cloud` and `git show origin/po/gw1-gateway-cloud:WILSON/docs/design/gateway-ticket-vectors.json > gateway/test/gw1-vectors.json`; a test that runs your verifier against it and SKIPS (named, not silent) when the file is absent. Your own `gateway/test/vectors.json` from the format above stands regardless; GW3 reconciles whatever still differs.

## Facts that will bite

- **`server.closeAllConnections()` skips a socket that has not finished its TLS handshake**, and `server.close()` then waits Node's 120 s `handshakeTimeout`: track every socket on `'connection'` (TCP level) and destroy them yourself; `handshakeTimeout` 10 s as the second bound (BC4's trap 2, Appendix A's last two rows).
- **Docker's default bridge hides every peer's address**: the container's bridge detection and the host-network rule are not optional (BC4's trap 6, R1/R2).
- **`\\localhost\C$` answers over loopback on this PC** (BC4's trap 3); a location refuses `localhost` and `C$` by the CLOUD's CHECK, not yours: the gateway serves whatever location list the cloud hands it and second-guesses nothing, so the local proof's fake cloud may hand it the admin share.
- **The app's untracked `.claude/launch.json` at the worktree root blocks the checkout**: move it to your scratchpad, never delete it (BC4's trap 1).
- **The Bash tool persists output over ~30 KB to a file**: read the design in slices.
- **A reviewer costs ~200k tokens a round**; budget two.
- **Web facts to verify on the day**: Chrome's local-network permission (since Chrome 142) for the preflight answer; name constraints are enforced by Windows, macOS and Firefox, historically not by Chrome on Linux (say so in the status page's help, not in code).
- **A subagent can overwrite your working tree**: after each review round, assert the executable form with failing controls before you commit its corrections.
- **A `<!--` in a long markdown file is a silent delete**: count the markers after editing the design or OUTSTANDING.
- **No real footage, ever**: the 256 MB file is random bytes; the fake cloud's clips are yours.
- **Nothing you build touches the desktop app or its Express server** (`electron/*` is read-only to you: copy the rules, share no module).
