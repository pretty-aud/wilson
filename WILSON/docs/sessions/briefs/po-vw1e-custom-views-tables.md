## Facts that will bite

- Move the untracked `.claude/launch.json` at the worktree root to your scratchpad before the checkout; never delete it. Insert your entry into the tracked one as text, anchored on its CRLF.
- **The Bash tool halves `\\` anywhere in a command**, a quoted heredoc (`<<'EOF'`) and a single-quoted string included (VW1d measured it with `od -c`), and an inline `node -e "…"` inside double quotes runs backticks as commands (VW1d lost a comment's words that way): text with backslashes goes through the Write or Edit tool. VW1d's other doc edits went through a small script that refuses unless each old passage matches exactly once and keeps the file's CRLF. Git Bash's `sed -i` turns a CRLF file into LF (harmless under `autocrlf`, but a later CRLF-anchored edit then misses).
- **The in-place Popover in React's StrictMode**: its cleanup runs once at mount and hands focus back to its trigger; VW1d's blur rule ignores that hand-back (`restoringRef`). Any new close-on-blur rule needs the same.
- **The lane CSS guards are shared** (`rabbitCssGuards.js`): a variable-valued `data-*` attribute in a guarded file must be declared in its guard's `VARIABLE` list; an inline `style` needs a `STYLES_ALLOWED` entry with a control.
- **A view's grouping by a kind whose column is gone** reads as none and is kept (opening a view is never a change); only a change for now forgets it (VW1b R1-10 as VW1d keeps it).
- **One field list serves a table and its card layout** (Board, Gallery): a field hidden on the cards is hidden in the table too; the Tasks Board keeps its card's own order (VW1d step 0, finding 6). Her answer to walkthrough 72 part 3's question 2 may change this.
- **jsdom keeps focus on a node React moves**, so a test of "the keyboard stays on the moved row" passes without the refocus code: assert the row's Tab stop too, and check once in Chromium (VW1d R1-3).
- **A drop needs the dragged id in `dataTransfer`** (`carried(e)` in `TableViewsMenu.jsx`, VW1d R2-5): a test's fake `dataTransfer` must answer `getData`.
- **A source pin reads from `process.cwd()`**, the WILSON folder, not the test file's folder.
- **Measure the toolbar in the bar's states too**: at 1280 the Tasks toolbar's *Filter (1)* alone takes it to two lines (17px); `scripts/vw1d-shots.mjs` writes its measures to a JSON beside the pictures.
