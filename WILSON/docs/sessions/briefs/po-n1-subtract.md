## Facts that will bite

- Move the untracked `.claude/launch.json` at the worktree root to your scratchpad before the checkout; never delete it. (In a desktop-app worktree the tracked file is the one the preview pane reads.)
- The Bash tool halves `\\` anywhere in a command, a quoted heredoc included; text with backslashes goes through the Write or Edit tool. Git Bash's `sed -i` turns a CRLF file into LF; `grep -c $'\r'` reports 0 on CRLF files there — count with node.
- A subagent can overwrite your working tree: after each review round, assert the executable form with failing controls before committing its corrections.
- The dev server reloads every open page when any file under `WILSON/` changes: write nothing there while a reviewer runs.
- Tests that read source by its code, not its name (FX15's trap: a pin read `display: currentPage === id ? 'flex' : 'none'` out of `App.jsx`): a moved or deleted line fails a pin far from it; the full suite finds it, a grep for the name does not.
- `src/ui/typeScale.test.js`, `dogCss.test.js`, `otterCss.test.js`, `rabbitShellCss.test.js` guard CSS by text; a deleted class may be one they expect.
- `src/dev/devFixtures.test.js` pins the fixtures' seams; the fixtures' routes are callers of adapter exports.
- The gateway's tests fail under the full suite's load on Windows (OUTSTANDING, the gateway entry): a red gateway test under `--maxWorkers=4` is known; run its files alone before reading it as yours.
- `node_modules` is absent in a fresh worktree: `npm install --ignore-scripts`, then `git checkout -- WILSON/package-lock.json`; `npm ls --depth=0` clean; the lockfile's sha1 unchanged in the hand-off.
- Never `supabase db push`, never `supabase config push`; nothing here touches a database.
