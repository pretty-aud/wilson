## Facts that will bite

- Move the untracked `.claude/launch.json` at the worktree root to your scratchpad before the checkout; never delete it. `node_modules` is absent in a fresh worktree.
- **An editor grant is a read grant** (0022's course arm): the chain ends at `user_h`, a plain member; a fixture user who exists for one probe gets that probe and nothing else.
- **A policy that reads its own table recurses**: the owner arm reads the `subject_owner_id` column and the guard asserts it against the live course at insert. Do not "improve" it into a subquery.
- **Locking the parent row is not locking the chain**: the row-maker locks every link above `FOR SHARE`, root first, and Appendix A's post-condition counts exactly one live `FOR SHARE`; a pgTAP suite is one transaction and cannot probe the race, so the post-condition is the pin.
- **A `NOT NULL` column with no default must be named in every forged-row fixture** (SH5, SHX and SHZ carry `subject_owner_id`), or the insert raises 23502 outside any `throws_ok` and aborts the file.
- **A definer that lists must test a link as the one that gates does**: the index's `gone` for a broken link is the helper's test, not the parent's status alone.
- **A GUC never set reads NULL, not `''`**: `is(coalesce(current_setting(…, true), ''), '')`.
- **The two-directional guard** in `rls.yml` names suites `NNN_<table>.sql` and enumerates the RLS-enabled tables of the CI database: a table in `RLS_TABLES` without its suite, or an RLS-enabled table in neither list, is red.
- **`supabase start` in CI applies every migration from the tree** to a fresh database: what is fine on dev, which skipped 0065, can fail there and say only "exit code 1"; the annotations are public, the logs are not.
- The design and the docs are CRLF, and the design is 3,227 lines: N2b found the Edit tool and `sed -i` unsafe on it and used a CRLF-preserving Python helper with every anchor asserted to occur exactly once, anchored on whole lines. The Bash tool halves a doubled backslash in a heredoc: scripts go through the Write tool. Count the HTML comment openers before and after in any long markdown file you touch.

- A subagent can overwrite your working tree: assert the executable form with failing controls after each round; `git status` clean, HEAD unchanged, `node_modules` 748 after each.
