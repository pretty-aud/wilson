## Facts that will bite

- Move the untracked `.claude/launch.json` at the worktree root to your scratchpad before the checkout; never delete it. `node_modules` is absent in a fresh worktree: `npm install --ignore-scripts`, then `git checkout -- WILSON/package-lock.json`.
- **`withTimeout` races but never aborts** (OUTSTANDING): an abandoned `getSession()` holds auth-js's global per-`storageKey` lock, which every PostgREST call awaits in `_getAccessToken()`. Bounding call sites fixes UIs, not the app. The fix is where the request is, not where it is awaited.
- **The SDK's fetch is the watchdog's**: `connectionWatchdog.js` wraps the one fetch supabase-js uses; an abort there is visible to the SDK as a rejected fetch. Measure what auth-js does with a rejected refresh before designing on it (a retry loop of its own, or a settled deferred).
- **Never sign in with her account**, never anywhere but wilson-dev's smoke user; a filename, a token or a key never reaches a transcript, a hand-off or a screenshot.
- **Electron and the web differ in the lock**: `navigator.locks` exists in both, but the Electron shell may carry more than one renderer; measure where the probe runs.
- The Bash tool halves `\\` anywhere in a command; text with backslashes goes through the Write or Edit tool. Git Bash's `sed -i` turns a CRLF file into LF. `src/` and the docs are CRLF.
- Vitest here reads `.env.local`; CI has none. Run the touched files once with it moved aside before pushing.
- A subagent can overwrite your working tree: assert the executable form with failing controls after each round. An HTML comment opener in a long markdown file silently hides everything to the next closer: count the markers.
