## 5. Traps hit

- **A bundle built in the worktree is not comparable with one built from an archive.** Vite inlines `.env.local`'s values: the worktree's build was 6.8KB larger than the same commit's from `git archive`. Build every compared commit the same way (here: an archive, `node_modules` linked by a junction, no `.env.local`).
- **`optimistic` reads `bundleRef`, which catches up only after a render.** A second write right after an awaited one starts from a snapshot that still holds what the first removed, and a refused write then puts it back on the screen. `rewireDependency` sets `bundleRef.current` itself after the unlink; its CONTROL failed until it did.
- **A queued verb must stay raw in `mutationsRef`.** The redo runs inside the undo queue; a queued verb called from there waits on itself until the queue's 20-second wait.
- **An inline editor at `width: 100%` (border-box) loses its own padding from its text.** Team members' Title cut "Producer" (54px) in a 58px cell until the field became `calc(100% + 8px)`, its padding in the cell's (review round 2); round 1 had blamed the share.
- **A width test is only as true as the crop that checked it.** Round 1's budget test passed while Chromium drew "Physical Productior" and an ellipsis after the Inactive pill: its floors were arithmetic (a select's padding, but not its borders or Chromium's inset; a pill "in the padding" that the kit cell's `text-overflow: ellipsis` still marks). Each floor in `pages.test.js` is now one Chromium measured.
- **A figure measured as `inline-flex` loses its spaces.** The rate cell's "$100,000 / $128,000" measured 148 that way and needs 156 with the spaces around the slash; the 13% that seemed to fit cut it by 4px.
- **`flex-wrap` with the name's `flex-basis: auto` sends a long name to its own line, away from the avatar.** `max-width: calc(100% - 32px)` keeps it beside the avatar (24px and the 8px gap).
- **Suite 104 needs explicit claims for the money gate:** `login_as` sets no `app_role`, so `can_access_project_money` refused the admin; the suite sets `request.jwt.claims` with `app_metadata.app_role` itself.
- **Adding a suite moves two lists:** `rls.yml`'s replay list and `rlsSuiteLists.test.js`, which pins the directory's last names (red in the full run until both moved).
- **Git Bash's `sed` and `cat -A` read a CRLF file in text mode and show no `\r`.** Check line ends with `file` or a Node count; this session edited CRLF files through a small Node script that keeps them.
- **`npx supabase` fails here; the scoop-installed `supabase` (2.90.0) works**, already linked to wilson-dev.
- **A hidden browser pane never runs `requestAnimationFrame`.** Layout reads must be synchronous there.
- **jsdom's `URL` is not Node's:** `readFileSync(new URL(…))` refuses it; read source files by path.
