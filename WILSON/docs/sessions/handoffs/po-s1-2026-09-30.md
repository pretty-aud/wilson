Prove the port with a marker file in `public/`.
2. 🚨 **A HAND CHECK THAT ONLY WATCHES THE MOTION PASSES A BUG.** S1's own frame-by-frame check reported "Day → Quarter (374.7, 35.3) → (67.2, 504.1)" as a smooth slide; the left edge should have stayed at 374.7 — the gantt had jumped months (round 1's HIGH). Compare the END state with the expected date, not only the frames between.
3. 🚨 **A LAYOUT EFFECT READS A CLAMPED `scrollLeft`.** After a zoom-out commits the narrower chart, the browser has already clamped the scroll; the anchor must come from before the commit (`lastScrollRef`).
4. **An element that unmounts cannot transition.** The minimap window was rendered only while on the minimap; a wrong intermediate box pushed it off and the remount jumped. Render it always under a clipping parent.
5. **A timer from the commit is not the transition's clock.** The slide starts at the next frame (70–160ms later on a Day-zoom render); a 200ms timer from the commit cut it (1–10px jumps). Drop the flag on `transitionend`, with a fallback.
6. **One px-per-character estimate cannot bound Geist** (§3 item 2). A lone space in a `nowrap` span measures 0; measure it inside a label.
7. **`v2Motion.test.js`'s regex counted `transition: none` as motion** (`:\s*(?!none…)` — the `\s*` backtracks to nothing). Fixed there with a control; `rabbitFilesCss.test.js` §9 carries the same line verbatim and was not S1's to change.
8. **`delete process.env.TZ` does not restore the zone** (Node 24); an empty TZ is UTC. Read `Intl.DateTimeFormat().resolvedOptions().timeZone` first and assign it back.
9. **The kit Tabs activate manually**: arrows move focus; Space presses the tab; Enter is eaten by the pet (P1-01) until S2a moves it to Shift.
10. **CI does not run on `po/**`** (see §2); `gh` is not signed in here — the repo is public, read runs anonymously (`api.github.com/repos/pretty-aud/wilson/actions/runs?branch=…`).
11. The listener effect with `[]` deps never attached when the Timeline opened on a loading project (the no-project return renders no gantt) — any effect that needs `detailRef` must depend on the gantt existing.
12. The two S1-era scripts that drive the app need the row scrolled into view (`scrollIntoView({ block: 'center' })`), or a grouping whose first task sits below the fold hovers nothing.
