## 5. Traps hit

- **The canonical checkout's `node_modules` was the demo branch's**: at this tip it lacked
  `@testing-library/dom`, `@testing-library/react` and `jsdom`, so every render test would have
  failed to load. `npm install --ignore-scripts`, then `git checkout -- WILSON/package-lock.json`
  (the install rewrote it). Check `npm ls --depth=0` before trusting a checkout's tests.
- **The desktop app's preview pane reads the session folder's `.claude/launch.json`**
  (`Claude_Work\.claude\launch.json`), not the repo's: the entry has to be in both.
- **A cold Vite dev server on the canonical checkout serves several thousand modules: up to two
  minutes to a mounted page.** Moving `.env.local` aside restarts it (it watches the file); once
  the page stayed blank afterwards until `preview_stop` / `preview_start`.
- **React DOM switches its own event dispatch off while a commit removes nodes**
  (`commitBeforeMutationEffects` to `resetAfterCommit`). A focus moved in a `useLayoutEffect`
  clean-up never reaches any `onFocus`/`onBlur`. Decide there; move focus in the passive clean-up.
- **Chromium decides `:focus-visible` when focus arrives**, by the last input (a key, or the mouse);
  a script's focus matches it. jsdom never matches it: stub it with that rule.
- **Chromium exposes CSS `text-transform` in accessible names** (FX13's trap), and Playwright's
  `ariaSnapshot()` does not show it: it computes names itself, in mixed case. Read Chromium's tree
  over CDP (`Accessibility.getPartialAXTree`).
- **The dev fixtures load a project in microtasks**, so one commit brings R.A.B.B.I.T.'s adapter and
  the whole project, and the provider's effects for the adapter run in a later task. A mount
  outside `act` whose waits pass in that gap sees the last used status `unavailable` (the table
  drawn, not *Loading views*) and loses a change for now to the drafts reset. Why CI and rarely
  here (review round 1, note 5): the Scheduler yields after the long commit, and RTL's `waitFor`
  drain (`setTimeout(0)`) must beat React's passive flush (`setImmediate`), which a loaded runner
  makes likelier. Render inside `act(async …)` and wait for the provider's own evidence.
  FX14-01 lists four more files with the same mount.
- **Testing Library cuts its DOM print at 7,000 characters**, so a CI annotation may stop before the
  part that decides (here, before the Group menu and the table body).
- **`grep -c $'\r'` in Git Bash reported 0 on CRLF files**; count line endings with node.
- **A planted fault matched on a string with a bare `\n` does not match a CRLF file**; the plant
  helper refuses when nothing changed (`PLANT FAILED`), so a non-plant is never read as a pass.
- **Team members' Export downloads a CSV**: not clicked. Deactivate on the last row, confirmed, is
  refused by the fixtures with a 6 s note and changes nothing: the walkthrough's timed note.
- **The dev server reloads every open page when any file under `WILSON/` changes**: nothing was
  written there while a reviewer ran (checked after each round).
