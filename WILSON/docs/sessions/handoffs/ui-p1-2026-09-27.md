## 5. Traps hit

1. **A CRLF plant that plants nothing.** The worktree's files are CRLF; a
   plant written with `\n` matched nothing and its CONTROL passed inertly.
   Match the file's own line ending, and assert the plant changed the file
   (its hash) before trusting a failure or a pass.
2. **Git Bash's `sed -i` writes a CRLF file back as LF, and its `grep`
   hides the CR** (`grep -c $'\r$'` reported every line CRLF on an LF
   file). Edit with the Edit tool or Node; count line endings with Node.
3. **A bare `:focus-visible` subject in a kit rule trips the lane guards**
   (`rabbitBudgetCss`'s kitOffsetRules, `rabbitFilesCss`'s kitFights). Name
   the kit's class in the subject (`.ui-drawer-head .ui-iconbtn:focus-visible`).
4. **Importing `scripts/ui-walk.mjs` runs the walk.** Syntax-check it with
   `node --check`.
5. **Shell quoting eats escapes.** A quoted heredoc ate `\\` in a
   template-literal regex (V2 trap 13 again), and a `node -e` inside double
   quotes lost a `\'` and broke a script. Write any file holding a regex or
   nested quotes with the Write tool.
6. **`[^>]*` in a JSX tag regex stops at an arrow's `>`.** Use a
   brace-aware scan (`rabbitCssGuards`' `jsxTags`).
7. **A ratchet kept as a floor under its residue.** When the count falls,
   set it to the measured count and prove "the pattern still matches" with
   a planted control (R1-08).
8. **A failed `git fetch` makes a stale merge look clean.** It failed once
   (network) and the merge said "already up to date" against the old ref.
   Fetch again before trusting it.
9. **The main checkout is one `cd` away** (`…/wilson/WILSON`). Run
   everything from the worktree.
10. **An outside build hung the first full walk** at screen 31. Walk in
    chunks under a timeout (eight chunks of about fifteen screens).
11. **The kit Switch's `label` prop draws visible text.** Where the row
    already names the switch (Settings), name it with `aria-label`.
12. **A face filing is broader than its text.** Chrome's platform-font
    report for an element counts its inline children's glyphs, so a filed
    parent excuses any fallback glyph inside it. File the face and a glyph
    ceiling (R2-08).
13. **The walk opens only a Help section's first page** unless a screen
    names a later one; that is how R1-01 escaped. Two screens now open
    D.O.G.'s later pages.
14. **Walkthrough 47 is generated, then hand-edited** (its pet section and
    one pointer). A rebuild drops both: patch the regenerated lines in.
15. **An extraction pass's "ruled" is a claim.** The six passes marked some
    questions ruled on a paraphrase; each was checked against its ruling
    before appendix A kept it (23 kept, 5 answered by later work).
