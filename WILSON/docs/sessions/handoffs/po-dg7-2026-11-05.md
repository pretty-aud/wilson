## 5. Traps hit

1. **`core.autocrlf=true`: every text file is CRLF in the working tree**, though `grep -c $'\r'` in Git Bash says 0. A Node
   script matching `\n` found nothing; split on CRLF and join back. Git stores LF.
2. **A regex inline in the Bash tool broke twice**, as the brief warns: write scripts with the Write tool.
3. **Saving a source file reloads the page under a running reviewer.** Hold edits until every reviewer has reported; docs are safe.
4. **`.sr-only` is `position: absolute`:** in a tile with no positioned ancestor its box is far above the scroller. jsdom cannot
   see this; only Chromium with many tiles did. A new `sr-only` inside a scrolled list needs a positioned parent.
5. **`useMemo` for the meter moved below the prompts' `useState`:** deps are read at render, so the old place would be a TDZ error.
6. **Git Bash `git rev-parse --short A B` fails; `cygpath` in an inline `node -e` path broke:** both scratch-only.
7. **Reviewers cost twice my estimate** when they measure in a browser: say a higher number.
8. **A test that passes here can time out on CI.** Round 1's and 2's plants took `dogCss.test.js`'s long CONTROL to 1,251ms on
   this PC and past 5,000 on a runner, since `pins()` read the sheet about 18 times a plant. Its pins are getters now, read when
