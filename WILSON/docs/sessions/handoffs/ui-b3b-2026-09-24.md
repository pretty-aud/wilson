## 5. Traps hit

1. 🚨 **THE BASH TOOL COLLAPSES `\\` TO `\`** — a fourth time, B1's, B2's
   and B3's trap: an appended test's regex (`\\s` became `s`, the guard
   failed on the real sheet). Anything with a backslash goes through the
   Write or Edit tool.
2. ⚠️ **jsdom has no `ResizeObserver`.** The first component mounted in a
   test that makes one on mount is `MinimapScrollbar`; the render test
   stubs it. A kit component that grows one will need the same.
3. 🚨 **THE BROWSER PANE DISPATCHES NO SCROLL EVENTS WHILE IT IS NOT
   PAINTED.** A click-to-jump scrolled the detail pane there, but the
   minimap frame (which follows the detail's `scroll` event) never moved.
   Measure gestures in Playwright (the probe, the gesture tool), never in
   the pane.
4. ⚠️ **A `pointer-events: none` label breaks a Playwright hover by text.**
   The minimap now names "Development" too, before the gantt's label in the
   DOM; `getByText('Development').first()` found the name and waited forever
   for it to take the pointer. Scope a locator to `.rb-tl-row` (the label
   row, before and after).
5. ⚠️ **`typeScale.test.js`'s inline-inventory scan runs 5–9s under a
   parallel run on this machine** (under 3s alone), past vitest's 5s
   default: it failed on time, not content, twice in six runs. It has 20s.
6. ⚠️ **The summary band's width budget at 1280.** Eight `Stat`s, the title
   and the zoom controls fit one line at 1280 only with 16px between
   figures. Anything added to that row wraps it there (+27px, measured).
7. 🚨 **PRE-EXISTING: A MINIMAP BAR'S DRAG NEVER COMMITS.** `OverviewBar`'s
   move handler writes `e.currentTarget._draftStart` on the mousedown's
   synthetic event, whose `currentTarget` React has nulled by then — a
   TypeError on every move — and the release saves the original dates.
   The release, off the bar, then clicks the row under it: click-to-jump.
   Identical on the old code. Left alone (a fix changes what a drag does,
   C1) and asked (§6 question 8); the gesture tool knows its exact
   signature, so a new defect of the same gesture still fails.
8. 📌 **Old-versus-new in the running app without touching the index:**
   copy the working files aside, `git show <sha>:<path> > <path>`, measure,
   copy them back. B3's trap 3 variant (its `git checkout <sha> --` updates
   the index).
9. 📌 **`estimateWidth` (7px a character) overestimates a name** ("Pre-production"
   is 82px drawn, 98 estimated), so a name moves beside its bar a little
   before it has to. By design: a name placed inside never overflows.
10. 📌 **What "300 KB" was, here:** B3's hand-off, the plan's four sections,
    the protocol, the review's nine findings, the sheet, the minimap module
    and contract, about 1,900 lines of `TimelineView.jsx` in ranges, the lane
