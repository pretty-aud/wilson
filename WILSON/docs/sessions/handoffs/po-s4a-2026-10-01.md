## 5. Traps hit

1. **PowerShell 5.1 and git messages.** `git commit -F -` with a
   here-string piped in is read as a pathspec; write the message to a file
   and `git commit -F <file>`. `Set-Content -Encoding utf8` writes a BOM
   that breaks `JSON.parse`; use the Write tool or node for JSON (or strip
   `\uFEFF` before parsing).
2. **The permission classifier refuses `Remove-Item` inside a compound
   command** ("system path '/' / '*' blocked"), and a wildcard path even on
   its own. Run `Remove-Item -LiteralPath <full path>` alone, one file.
3. **The working tree is CRLF** (autocrlf) while new files are written LF:
   a mutation anchor written with `\n` misses a CRLF file. The scratch
   runner `mutate.mjs` converts to `\r\n` when the LF anchor is absent, and
   restores byte for byte. Read vitest's "Tests N failed" line, not the
   first "N failed", which is a per-file count.
4. **A module-level Set in the explorer** (`PREVIEW_READS_LOGGED`, E13's
   once per session) leaks between tests; reset it in `beforeEach`
   (`_resetPreviewReadsForTests`).
5. **`expect(undefined).not.toBeNull()` passes.** Use `toBeTruthy()` for
   "it is there".
