**What the two review rounds changed on the gateway's side of the wire** (GW2 builds these; the vectors file's `for_gw2_from_gw1` carries them):

- **The reach probe's answer is a proof, not an echo.** While a sync's answer has `check_reach_now: true` it carries `reach_nonce` (32 lower-case hex), at every sync until the check ends. The cloud then sends `GET /v1/health` over TLS to the outside door with the header `Wilson-Reach-Nonce`; the gateway answers `200 {"ok": true, "nonce_proof": "<64 hex>"}` only when the header carries the nonce its last sync handed over, else `200 {"ok": true}`. `nonce_proof` = HMAC-SHA256(key = the UTF-8 bytes of its **reach key**, message = the UTF-8 bytes of the nonce), the reach key being the lower-case hex SHA-256 of the UTF-8 bytes of `wilson-reach-key:` followed by its own `wgc_` credential string (round 2; round 1 keyed it by the credential's own hash). `reach_probe.proof_vector` is a worked example with a fixture credential (credential → reach_key → nonce_proof). `nonce_echo` is not read; an echo reads as *not this gateway*. **GW2's gateway, as merged at `f340e41a`, still answers the echo** (`gateway/src/doors/handler.mjs`): OUTSTANDING's entry.
- **The inside door closes a public peer at once, before TLS** (GW2 does): that close is how the cloud's check tells the inside door reached from the internet (red) from a tunnel's edge on the same port (plain).

## 5. Traps hit

- **The Bash tool's heredocs collapse `\\` to `\`** (broke Python string matches, Windows paths and JSX escapes): write such files with the Write tool, or build backslashes with `chr(92)`. Long heredocs end in "unexpected EOF": write the script to the scratchpad and run it.
- **`supabase db query --linked` with several statements answers only the last one's rows**; query one statement at a time. `npx supabase` fetches the npm CLI (2.120) where scoop's `supabase` is 2.90; use the installed one.
- **`src/dev/devFixtures.test.js` pins the seams and the fixtures' imports**: a new production file that consults the fixtures joins `SEAMS` (and `guarded`, if it makes a network call), its guard on a line naming `import.meta.env.DEV && devFixtures()`, and no production file may even NAME the fixtures' path in a comment; an app module the fixtures import joins `allowed` with a proof that it imports nothing.
- **`src/ui/typeScale.test.js` allows only weights 400 and 600, and every border of 2px or more must be one a person judged**: a new heavy edge is refused; use the existing forms (`.s-feedback[data-tone]`, `.s-well`).
- **A test that needs the workspace role in the Bins tab**: `useProjectAccess()` returns `gateCtx.appRole`; BinsView must not import `usePermissions` (its tests have no Supabase address, and the client throws on import without one).
- **The safety classifier refused deploying a measuring build** that would reach out from the Edge runtime; measure through the real function instead.
- **A `rm` whose target is a shell variable is refused**; use literal paths or `"${VAR:?}"`.
- **GW2's `gateway/test/docs.test.mjs` pins GW2's row as the first of OUTSTANDING's session log.** A session that adds its row on top (the file's newest-first order) fails it; GW1 put its row directly beneath GW2's (the same day's tandem pair). The next session whose row belongs on top should loosen that pin ("GW2's row is in the log") rather than bury its own row, and say so in its hand-off: it is GW2's file.
- **`grep -c pattern file && cat >> file` appends nothing when the count is zero**: `grep -c` exits 1 on no match, so the `&&` skips the append without a word. Check the count separately, or append from Python.
- **The file-writing tool decodes `\u` followed by four hex digits in what it writes** (some of them: `\u2028`, `\u200b`, `\u202e` became the characters themselves, raw bidi and zero-width characters, in a migration and a TypeScript file; the controls below `\u00a0` did not). A source file must never carry them raw (a raw direction override reorders what a reviewer sees). Type such escapes through a placeholder (`'@@u'` replaced by `chr(92) + 'u'` in the script), and scan what was written for the code points.
- **`to_jsonb(E'…')` of an untyped literal fails** (`could not determine polymorphic type`): cast it, `to_jsonb(E'…'::text)`.
- **A Python runner writing to a redirected file on Windows dies on an emoji** (cp1252): run it with `PYTHONIOENCODING=utf-8` (suite 96's probe names carry 🚨).
