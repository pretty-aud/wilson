## 5. Traps hit

1. 🚨 **THE BASH TOOL COLLAPSES `\\` TO `\` BEFORE THE SHELL SEES IT** — even
   inside single quotes (`printf '%s' 'a\\b'` prints `a\b`). A regex written
   into a heredoc or a `node -e` lost half its escapes three times (a test
   that would not transform, a crop script, an unused-import scanner that
   reported every name). Write anything with a double backslash through the
   Write/Edit tools, into a file.
2. 🚨 **`.claude/launch.json` IS TRACKED ON THIS BRANCH**, so a local launch
   entry blocks every `git merge` that touches it. Set the entry aside, merge,
   re-add it. Removing the entry, even for a second, makes the desktop app
   STOP the dev server it started — the first walk after GO hit
   `ERR_CONNECTION_REFUSED` for that reason; re-prove the server with a marker.
3. 🚨 **EQUAL SPECIFICITY WITH THE KIT IS A COIN TOSS, AND THIS SHEET LOSES
   IT.** A component-imported sheet can load before `index.css` (it did in
   dev), so `.rb-x` against `.ui-input` (both 0,1,0) went to the kit and a
   state painted nothing (Team's sort). A rule on an element that also wears
   a kit class needs (0,2,0)+. `weakAgainstKit` enforces it.
4. 🚨 **THE UTILITIES LAYER BEATS EVERY COMPONENT RULE.** `text-h3` carries
   its weight, `rounded-control` its radius; a component rule for the same
   property on the same element is inert however specific it is. Change the
   element (two spans, drop the utility), not the specificity.
   `utilityConflicts` enforces it.
5. ⚠️ **A TOKEN MAPPING BY OLD HEX CAN MAKE A THING INVISIBLE.** `#44403c` as
   a ground was a lighter strip on a `#292524` card; both map to
   `paper-raised`, so three dividers and the Team avatar drew nothing. Check
   every place the old palette used two neighbouring greys against each
   other.
6. ⚠️ **ONE `data-state` NAME, THREE ELEMENTS.** A dynamic value on one
   (the adapter dot) excused a typo on another (the step strip) until the
   attribute guard was scoped by class.
7. ⚠️ **ELECTRON'S `minWidth` IS 1024** (`electron/main.cjs`), not the plan's
   700 — the narrowest a R.A.B.B.I.T. view can be. The tab strip wrapped
   there. The fix keys to the STRIP's width (a container query, below 1240px
   the icons drop and the tabs tighten), not the window's: a viewport media
   query broke again with eleven tabs at 1153–1239 (round two).
8. 📌 **THE KIT INPUT AND SELECT ARE NOT DROP-IN.** `Select` turns `''` into
   `null`, `Input` hands back a value not an event and adds Enter-blur /
   Escape-revert. Native fields wearing `.ui-input` keep C1.
9. 📌 **RENDERING ONE NODE UNDER TWO PARENTS REMOUNTS IT.** The presence strip
   moves between the context bar and the tab strip; any hook inside refires
   on every Summary crossing. Hoist fetches to the shell.
10. 🚨 **`overflow-x: auto` MAKES `overflow-y` AUTO TOO**, and a 1px negative
    margin inside is then a vertical overflow: a stray scrollbar on every
    screen and the tab underline clipped to 1px. Set `overflow-y: hidden`
    whenever you set `overflow-x`.
11. 🚨 **PLAYWRIGHT HIDES SCROLLBARS BY DEFAULT**, so the walk's screenshots
    could not show finding 10 — round two turned them on to see what Electron
    on Windows draws. Measure `scrollHeight` / `clientHeight` instead of
    trusting a headless screenshot for anything that scrolls.
12. ⚠️ **`title=""` IS NOT "NO TOOLTIP" FOR A CHILD.** Chromium takes the
    tooltip from the first ancestor with a title attribute and `""` counts,
    so an empty title on a nested element makes it a dead zone. Pass the
    parent's title down instead.
13. ⚠️ **`outline-none` IS A UTILITY AND BEATS THE BASE FOCUS RING.** A bare
    input inside a bordered wrapper needs the ring on the wrapper
    (`:has(:focus-visible)`); `scripts/sweepOutlineNone.mjs --dry` finds
    stragglers.
