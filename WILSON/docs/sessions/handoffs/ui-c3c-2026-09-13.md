3. **🚨 A GUARD THAT HOLDS YOUR WORK CAN BLOCK THE FIX FOR YOUR OWN DEFECT.**
   The two sentence-case parentheticals inside a field label inherit the Label
   token's 0.06em. The one utility that cancels it is `tracking-normal` — and

   thing to keep the suite green.**

4. **🚨 A MUTANT THAT MISSES ITS TARGET PROVES NOTHING, AND READS AS PROOF.**
   A `.at-prose` mutant replaced the FIRST `font-size: var(--text-dense)` in a
   sheet that has ten of them, so it edited a different rule and the guard
   reported green. I nearly recorded "the guard is inert". Re-anchored to
   `.at-prose` itself it fails correctly. **Before concluding a guard is inert,
   prove the mutation landed where the guard is looking.** This is C3b's trap 6
   with the count replaced by a test result.

5. **🚨 A MUTATION HARNESS NEEDS ITS OWN POPULATED-CHECK.** My replay harness
   passed a stripped environment to `subprocess`, `npx` never started, every run
   produced no output, and "no failures found" read as GREEN — **for all 34
   mutants at once**, which is the only reason it was obvious. It asserts
   `"Tests "` appears in the output now. A test harness is a derived list too
   (C3b trap 8).

6. **A HEREDOC MANGLED A PYTHON SCRIPT THREE TIMES**, exactly as C3b's trap 5
   says it will: once silently dropping `\n` inside a string (SyntaxError), once
   emitting `SyntaxWarning: invalid escape sequence` on `\s`, once producing an
   unterminated literal. **Write the script with the Write tool and run it by
   path.** Every heredoc I used had to be redone; not one saved time.

7. **`od -c` LIES ABOUT LINE ENDINGS TOO, IF YOU GREP ITS OUTPUT.**
   C3b's trap 7 says use `od -c` instead of `grep -c $'\r'`. But
   `od -c | grep -c '\r'` counts *lines of od output*, not carriage returns,
   and told me a region was CRLF when Python reading with `newline=''` showed
   it was LF. **Read the file in Python with `newline=''`; that is the only
   answer that has been right every time.** The file was genuinely mixed —
   `docs/walkthroughs/27_ui_admin_terminal.md` is CRLF with an LF part three,
   because the append was a shell heredoc.

8. **Two subagents sharing one scratchpad root overwrite each other.** Round
