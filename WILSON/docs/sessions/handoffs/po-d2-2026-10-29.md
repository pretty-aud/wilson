## 5. Traps hit

- **Electron 33's `navigateOnDragDrop` is false by default**: a dropped file never left the page on the tip. D1-01's drop was an inference from a main-process `loadURL`. A drop through the DevTools protocol takes the real path (a control build with the setting on lands on the file).
- **The app's own cloud downloads were navigations of the window** (`a.href = signed; a.click()`, no `download`: cross-origin) — a grep for `location.href` and `<a href` missed them; round 1 found them. Any navigation guard must give them another path.
- **react-markdown's default anchors have no target**, and remark-gfm turns an email address into `mailto:`: the pet's and O.T.T.E.R.'s links are top-frame navigations (round 2).
- **Listener order**: a document-level guard registered at boot runs before Bins' document listeners and takes the drop they read as unhandled; on the window, bubble phase, it runs last.
- **The Bash tool eats backslashes** in heredocs and in `node -e` strings (met twice: the helper refused the edit both times before writing); edits with a backslash go through a script file written by the Write tool.
- **A source slice that ends at the first `});`** can stop inside a line; **`loadURL` is inside `downloadURL`**.
- **The fixtures' company files include a gated invoice file with the same name** as the M2 fixture's path invoice: a search for an invoice's name needs names found nowhere else. **JSON doubles a backslash**: a path is searched in its escaped form too.
- **A planted control can expect the wrong thing**: with the judgement moved after the recording, the cap still ends the session (activity cannot extend a cap); only the idle cases fail.
- **`rm -rf "$VAR/x"` is refused by the harness's safety check**: literal paths, or `${VAR:?}`.
