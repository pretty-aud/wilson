## 5. Traps hit

- **Bash heredocs halve backslashes and mangle non-ASCII text** (the brief warned of the first).
  An edit script's `\r\n` anchors became real line breaks, and a design paragraph's "…" and "—"
  stopped matching; each script's own anchor count stopped it and nothing was written. Scripts
  with backslashes went through the Write tool; paragraphs were re-wrapped by line number.
- **Line endings differ file by file** (autocrlf): most working files are CRLF, but files this
  session wrote whole (`TaskItemCells.jsx`, `Popover.jsx` and its test, two test files,
  walkthrough 72) are LF. A failing control anchored on `\r\n` found nothing in an LF file and
  was skipped instead of failing (R1-5, re-run with the right anchor). The round 2 script
  treats an anchor found other than once as a broken control.
- **Chromium 152 and `scroll-padding-left` with sticky columns** (R1-2, measured): the browser
  treats everything left of the padding as outside the view, so focus inside a sticky cell
  scrolled the table back to its start.
- **Focus lands on a pointer press, before the release** (R2-3): a rule that scrolls on
  `focusin` moves a control out from under a pointer that is still down, and the click is lost.
- **jsdom says a bare button's border is 16px** (`getComputedStyle`), where a browser says 0 for
  a border with no style: measuring code that subtracts borders must ask the style first.
- **Playwright's `scrollIntoViewIfNeeded` scrolls a row wider than its scroller sideways** (12px
  once the scroll padding went): `scripts/vw1-shots.mjs` puts the table back at rest after it.
- **In `npm run dev` (React's StrictMode) the Popover's effect runs twice**, and the first
  cleanup's focus-back scrolls a cell under the Title clear of it (round 2's reviewer measured
  it). The production build runs it once, and the picker opens at the Title's edge.
- **The kit's `data-` guard** (`src/ui/dataState.test.jsx`) refuses presence-keyed selectors in
  kit CSS: the sticky rules key on `data-sticky="true"` and `data-sticky-columns="2"|"3"`.
- **The lane CSS guards are shared** (`rabbitCssGuards.js`): the sticky kit rules first failed
  OTHER lanes' `kitFights` checks; the guard now counts them only where a Table passes
  `stickyColumns`. `stateLeaks` refuses an inline `style={variable}` (one literal is allowed in
  `STYLES_ALLOWED`); the date-cell padding guard read `[data-col="bid"]` as maybe matching, so
  `data-col` joined `KNOWN_ATTRS`.
- **Moving `ASSET_TYPES`** broke two guards that read it where it was (`devFixtures.test.js`'s
  import proof, `fixtures/dataset.test.js`), and `rabbitFilesCss.test.js` pins the entity
  configs' fields (`assetsKey` added).
- **A module-level store leaks between tests**: `useTaskItemSort`'s fallback needed
  `_resetTaskItemSortForTests()`.
- **Two tests flake only under load** and pass alone: `timelineWeekends.test.jsx` and
  `state/rabbitShotLists.routes.test.js` (a port collision); neither is VW1b's.
- **A build run outside the worktree**: one build's output landed in
  `.claude/worktrees/vw1b-buildcheck` (outside this worktree) and was deleted. Build into the
  scratchpad.
- **The Browser pane was hidden** for the whole session, so every real-browser check ran in
  Playwright against 5298, loaded through `createRequire` on the app's `package.json`, with
  `ignoreDefaultArgs: ['--hide-scrollbars']` for real scrollbars.
- **The dev server reloads every open page when any file under `WILSON/` changes**, docs
  included: re-open the page after an edit before measuring.
- **Walkthrough 74's note first said all six questions were answered**; four were (Q-N5 and
  Q-N6 were not asked). Read the questions file before counting answers.
- **A grouping by an item kind is forgotten on a project without that kind** (R1-10, as built):
  grouped by Level, switch to a project whose table has no Level column and back, and the table
  is no longer grouped; a Status, Phase, Priority or Assignee grouping survives the switch. A
  saved view keeps its own grouping (loading one never writes the remembered one).
