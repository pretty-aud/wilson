## 3. Done and verified

**The design, in one paragraph.** `LEGAL` joins the one list of locked
folders (`rabbit_money_segment`), so the sixteen storage policies,
`files_money_provider_chk` (Legal bodies never leave Supabase) and the
bounded quota exemption take it with no restatement. `file_row_is_money(flag,
path)` is the one definition of a money files row on both axes; the four
`files_*` policies are restated from their latest bodies with it in USING
and WITH CHECK. `files_legal_folder_chk` ties the `legal` tag to the
`LEGAL` folder; `trg_files_legal_fixed` keeps a path from crossing that
boundary after INSERT; `files_legal_not_core_chk` keeps a Legal file out of
Core; `files_money_key_chk` makes every locked path a real
`projects/{id}/{SEGMENT}/…` key. Everything else that could name a Legal
file — realtime, edit history, trash, the download log, the deletion
certificate, reservations, the sweep's certificate, the quota meter — is
gated (§"What a reviewer or member can and cannot see"). The client adds a
file as Legal only through Add as Legal (money-cleared people only), never
by a tag. The Local Server keeps a real `LEGAL` folder it cannot lock and
says so.

## 5. Traps hit

1. **The Bash tool collapses `\\` inside heredocs** (a here-doc'd Python
   script with `'\\n'` arrived with real newlines and a SyntaxError). Write
   any script with backslashes through the Write tool and run the file.
2. **`preview_start` reads the worktree ROOT's tracked `.claude/launch.json`**,
   not `WILSON/.claude/launch.json`. Add a local entry there (env through
   `cmd /c set VITE_DEV_FIXTURES=1&& …`) and revert it at the end.
3. **The worktree has no Electron binary** ("Electron failed to install
   correctly"). Playwright's `_electron.launch({ executablePath:
   '…/wilson/WILSON/node_modules/electron/dist/electron.exe', args: ['.'],
   cwd: <worktree WILSON> })` runs this worktree's code on the main
   checkout's binary (same 33.4.11). Remove the development `dist/`
   afterwards (`devFixtures.test.js` scans it).
4. **`pg_trigger.tgattr` is an `int2vector` with a 0-based bound**: cast to
   `int2[]` it never equals `ARRAY[n]`. Compare `tgattr::text`.
5. **An UPDATE of a row that is not there raises nothing.** Suite 90 purges
   its Legal fixture in §I; the first draft of probes 90 and 92 targeted it
   and passed vacuously. §K inserts a fresh Legal row.
6. **A BEFORE trigger answers before RLS's WITH CHECK, which answers before
   a CHECK constraint.** Adding `trg_files_legal_fixed` silently re-pointed
   which refusal probe 38 saw; it now isolates WITH CHECK on the flag axis.
7. **`supabaseAdapter` keeps the client it first saw**: a test that swaps
   fake clients must call `resetSupabaseAdapter()` between them.
8. **`mutate.py` restores the bytes it read**: never edit `src/` or
   `electron/` while a reviewer's harness runs — the edit is lost.
9. **`rabbitFilesCss.test.js`**: a `data-*` attribute set from a variable
   in R.A.B.B.I.T.'s components must have a stylesheet rule; do not add
   test-only data attributes there.
10. **Two extractors, two answers.** `split_part(path,'/',3)` and
    `storage.foldername(path)[3]` disagree on `projects/{id}/LEGAL` and on
    keys that do not start `projects/`; `files_money_key_chk` now makes
    them agree for rows.
11. **`readRabbitBundle` runs on every Local Server request**, and
    `GET /api/rabbit/projects` reads every project's bundle: anything added
