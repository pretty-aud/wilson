## 5. Traps hit

- **The holder is held until the SDK's queue drains**, and returns its own loop's result (no session) however late: the first phase F expected it to settle at ~42 s and waited 70 s for nothing. Its read then goes out with the anon key unless refused.
- **A ping that answers is not a service that works:** GoTrue's `/health` and PostgREST's root answer while the database behind them is stuck; clearing on them made the strip flicker every budget (round 2 measured it). Only a request that does the work proves it.
- **A sign-out during a hang:** the SDK's `signOut` queues behind the hung refresh, then runs on the dead network, and a retryable error removes nothing — the session the person ended stays in memory and would be re-saved by the next `TOKEN_REFRESHED`.
- **auth-js's `_setSession` checks a fresh token with `GET /user`** (the server refuses a made-up signature): the probe answers that one request itself to seed a session; an expired token goes to the refresh first and is saved only on success.
- **Every body was a second:** `Math.ceil` on the scale gave the refresh's `{refresh_token}` body a 21 s budget; and `String.length` counts UTF-16 units, not bytes.
- **Fake timers and auth-js:** `vi.advanceTimersByTimeAsync` carries the SDK's backoff sleeps and its 30 s window; the two attempts of a 20 s budget end at ~40.5 s.
- **Node 24 has `navigator.locks`** but auth-js's `isBrowser()` wants `window` and `document`; the lock choice is `persistSession`'s anyway.
- **`node -e` with a `/c/...` path fails** (`C:/...` works); the Bash tool halves backslashes; `git diff --stat` from the app folder shows paths from the root.
- **The desktop app from Playwright:** `_electron.launch` with the main checkout's `electron.exe` and this worktree's `electron/main.cjs`, `app.context().route` for the stub, `setContentSize` per size, `app.exit(0)` before `close()`; a development-mode build in `dist/`, removed after (`devFixtures.test.js` scans a `dist/`).
- **`vi.stubEnv` before importing a module that reads `import.meta.env`** at load; `vi.resetModules()` per test.
- **The walkthroughs README's rows are in ascending order**; an Edit anchored on the next row's start inserts above it.
- **`git merge -F -` does not read stdin** (`git commit -F -` does): it failed with *could not read file 'WILSON/-'* and left HEAD at the integration tip, nothing merged or pushed. Write the message to a file and pass its absolute path.
