## 5. Traps hit

1. **jsdom does not honour `inert`.** GatedAction greys a control by making
   its subtree `inert`; in the tests a click still reaches the handler. A
   test that only checks the grey proves nothing about the write: every
   funnel checks the gate itself, and the reviewer tests click through and
   assert no write.
2. **The kit-fight guard sees a field the moment it can be disabled.** The
   lane's empty-value colours on dates and selects tie the kit's
   `.ui-input:disabled`; the fix is `:not(:disabled)` on the lane rule.
3. **A GatedAction wrapper is a new box.** Where the lane positioned a
   control by a child selector, the greyed wrapper breaks it: give the
   wrapper its own class and rule (`rb-scene-nest-delete-gate`,
   `rb-scene-bulk-gate { gap: inherit }`).
4. **Menu words appear twice** — the live item and its greyed twin — so a
   test that greps the label passes on a half-rename; pin the live one.
5. **The sentence-case walk** (helpContent.test.jsx) fails a capital
   mid-heading ("…, or Delete").
6. **The desktop app in a worktree.** `npm install --ignore-scripts` leaves
   `node_modules/electron` without its binary: launch the main checkout's
   `electron.exe` (the same 33.4.11) by `executablePath`, reading it only.
   `main.cjs` takes the single-instance lock BEFORE its `WILSON_USER_DATA`
   override, so any running WILSON makes the new one quit at once — and that
   instance's `second-instance` handler RAISES its window on Audrey's screen
   (S3b's first, lock-blocked launch did this; three Electron processes from
   the main checkout were running then, and were gone by the end, not
   stopped by S3b). Pass `--user-data-dir=<scratch>` as well. The app routes
   in-app, so `page.goto('/rabbit')` lands on Home; click Home's entry. The
   Local Server's create-project route takes `title`, and the Scenes tab
   needs `scenes_enabled: true`.
7. **`vite build --mode development` leaves `dist/` with the fixtures'
   text**, and `devFixtures.test.js` then fails the full suite. Delete
   `dist/` after a desktop check.
8. **Playwright text locators match hidden `<option>`s**: add `>>
   visible=true`. And a control inside an `inert` GatedAction is out of the
   accessibility tree: find it by its text (`hasText`), not its role.
9. **This shell tool breaks heredocs with apostrophes**; write scripts with
   the Write tool, and make exact replacements through a small script that
   refuses an anchor found zero or two times (CRLF-aware).
10. **The planted-fault runner restores files byte for byte**; do not edit a
    file it is mutating while it runs.
11. **Chromium's microtask checkpoint, and React 19.** A trusted event runs a
    microtask checkpoint after EACH listener, and React 19 flushes an update
    made in a native listener there — render, commit and effects. So a
    document-capture listener that changes state (the kit Menu's outside
    press) has re-rendered the tree BEFORE React dispatches the target's own
    handler. jsdom runs a dispatch in one stack, and `fireEvent` wraps it in
    `act()`, which defers the flush: the old order, which hid round 1's
    MenuButton fault. Test such code with `browserOrder()`
    (`views/scenes/MenuButton.test.jsx`: flushSync after each
    document-capture listener, native events, `IS_REACT_ACT_ENVIRONMENT`
    off), and in jsdom's order as a control.
12. **The provider's undo batch is ONE global slot, and a step is pushed when
    the backend answers.** Anything awaited inside `runBatch` holds the slot
    open: other edits join it, an undo pressed meanwhile undoes the step
    before it, and a replay records nothing (S3b-10). And never run
    `optimistic()` deletes side by side: a refused one's rollback restores
    the whole bundle from before it began, putting back what the others
    deleted.
13. **"Inside the batch" is measured when the step lands, not when the call
    starts.** A probe that notes depth at the call is fooled by an empty
    batch opened beside the calls (`batchProbe`, round 2).
14. **The Scenes key handler is bound only where the bins are
    (`supportsBins`).** A key test without `TAKES` passes vacuously; give
    every key test a control that the key does act.
15. **CRLF.** A regex ending in `\n` never matches a CRLF source file read
    raw (`writeGate.test.js`): use `\r?\n`.
16. **A guard written twice leaves each single planted fault surviving** (a
    render-time check and the effect that clears the state one render
    later): plant the pair, and record the single one as covered.
17. **CI's pgTAP job can fail before running anything** — the Supabase CLI
    setup hits GitHub's API rate limit (exit 127). Look at which job failed
    and why before reading a red run as the code's.
