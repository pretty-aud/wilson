## 5. Traps hit

1. 🚨 **THE BRIEF'S BASELINE WAS WRONG, AND THE REASON HAD BEEN LIVE SINCE
   T0.** `npx vitest run` at `e1b5c31` is **139 / 2823** on Windows, not
   140 / 2858. `src/ui/typeScale.test.js` cannot COLLECT, and vitest reports
   that as a failed SUITE with ZERO failed tests — the summary stays calm
   while T0's entire 35-case guard silently does not execute.

   Git for Windows ships `core.autocrlf=true` in its SYSTEM config, so every
   checkout gets CRLF although every blob is LF. Vite's SSR transform hoists
   imports to the top of the rewritten body and strips a `#!/usr/bin/env node`
   hashbang on the way past — but only an LF-terminated one. With CRLF the
   hashbang survives, lands mid-body, and `new AsyncFunction(...)` throws.
   Fixed with `*.mjs text eol=lf`, which changes no content.

   **CI never saw it: CI is Linux.** All three lanes hit it within minutes of
   each other and wrote three different fixes. **If you are in a worktree cut
   before `b4eac8f`, `.gitattributes` does not convert files already checked
   out** — merge, then convert them in place or delete and re-checkout.

2. 🚨 **A MUTATION THAT SILENTLY FAILS TO APPLY IS INDISTINGUISHABLE FROM AN
   ASSERTION THAT CANNOT FAIL.** It happened three times here: a perl
   substitution that did not match, a Python one whose search string was LF
   against a CRLF file, and one defeated by an em-dash. Each produced a green
   suite that read exactly like "the control is inert". **Assert the mutation
   landed before running the suite.** T0's trap 13 is the same lesson from
   the other end: there the control was inert, here the experiment was broken.

3. 🚨 **A SECOND IMPLEMENTATION OF THE SAME PARSE IS A SECOND PLACE FOR THE
   SAME HOLE.** Round two found `TYPE.huge` walking back in through a helper
   that matched `\.[a-z0-9]+` after the main regex had been enumerated to
   stop it; and a regex comment-stripper that could not see strings, beside a
   scanner that could. Both are one implementation now. If you find yourself
   writing a second reader of the same syntax, delete the first.

4. 🚨 **THREE LANES MET IN ONE GUARD FILE, AND THE MERGE SILENTLY REVERTED
   THREE CORRECTIONS.** `typeScale.test.js` had eight conflicting regions.
   Git resolved what it could and I resolved the rest, the suite was green,
   CI was green — and round two found that a `lineHeight` assertion, a
   judged-border SET assertion and a fixed denominator had all been dropped
   in favour of the other side's older shape. **A merge can undo a fix with
   both sides green and nothing red.** Two things follow:
   - after a large conflict resolution, re-read the diff against BOTH parents,
     not just the test result;
   - a fix expressed as an ASSERTION survives a merge in a way a fix expressed
     as a comment or a narrowed regex does not.

   The same merge separated an exemption from the site it described — neither
   parent was inconsistent, the staleness was created by combining them.

5. 🚨 **JSX TREATS A STRAY `)}` AS TEXT, NOT AS AN ERROR.** The dialog rewrite
   left a second `)}`. esbuild compiled it to a literal `")}"` child of the
   app root. Build clean, 67 tests green, and the quit-dialog guard's own
   window ended one line above it. A structural edit to JSX wants a look at
   the COMPILED output, not just a passing build.

6. ⚠️ **A SCRIPT THAT ONLY PRINTS CANNOT BE GREEN.** `ui-page-check.mjs` had
   no exit code and no floor, so "0 errors / 0 overflow / 0 off-scale on
   twelve pages" was a human reading a table — and a page that loaded but
   rendered nothing printed the same three zeros as a perfect one. It exits
   non-zero now and warns under ten text nodes. Proved: an off-scale 21px on
   the page title names 11 pages and exits 1.

7. ⚠️ **A COMMENT QUOTING A CLASS NAME ADDS AN AUDIT HIT.** Writing a tracking
   utility's name in prose took that row from 3 to 4. Repo-wide, 65-odd hits
   across the audit are comments. Describe the class; do not spell it.

8. ⚠️ **`\bem\b` MATCHES NOTHING AGAINST `0.9em`, AND `\b` SITS INSIDE
   `1.5px`.** The word-boundary trap twice more, in both directions: once
   silently accepting seven real hits, once reporting a correct hairline as a
   defect. That is five times in this bundle and T0 hit it four.

9. ⚠️ **AN EXEMPTION WINDOW IS A THRESHOLD, SO MEASURE IT.** `sweep`'s ±140 is
   too narrow for the frozen transition title: the string identifying the
   element ends ~155 characters from its `fontSize`, so two of five
   declarations matched their exception and three did not. ±400, measured.

10. 📌 **DEVICE PIXEL RATIO CHANGES THE CARET'S ROW HEIGHT AND NOTHING ELSE.**
    In a browser pane at DPR 1.5 the rows are 27.46px, not 27.80 — a 1px
    border snaps to one DEVICE pixel, 0.667 CSS px. Every other axis still
    reads 0.00 and a 240px field still measures 240.000px. Playwright defaults
    to `deviceScaleFactor: 1`, which is D2's condition. **Do not compare 27.46
    against AuthShell's comment and conclude the row moved.**

11. 📌 **`git checkout <sha> -- src/` IS BLOCKED BY THE APP'S CLASSIFIER**, and
    rightly — it is also T0's traps 8 and 10. To screenshot a "before": back
    the file up with `cp`, edit it with a script that ASSERTS its
    substitutions applied, shoot, restore with `cp`, confirm `git diff --stat`
    is empty.

12. 📌 **F1'S HAND-OFF §8 IS STALE.** It says `AuthShell.jsx` still carries a
    private mono stack at weight 700. It does not, and has not since D2: the
    family is `FONT_MONO` and the weight is 600, with the reason beside it.

13. 📌 **THE AUTH SIGN-IN SCREEN TAKES ~9 SECONDS** and only exists with
