  Browser pane).

  the next; `beforeEach` now resets and sets the never-answering default.
- **A made full deck calls the AI again** (its theme), so count "at least one more call" and read
  the first.
- **Chromium exposes CSS `text-transform` in accessible names:** `.ui-field-label` is uppercase, so a
  label-named field is *DECK CONTEXT & GUIDELINES* to a screen reader; jsdom (no CSS) says the
  mixed case.

  page (FX13-02). A message a keyboard user must read should not time out.

  `focus({ preventScroll: true })` then `scrollIntoView({ block: 'center' })`.

  Chromium probes included: nothing was written under `WILSON/` while a reviewer ran.
