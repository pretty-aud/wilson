## 5. Traps hit

1. **Node 24's `spawnSync` with `shell: true` concatenates the arguments**, so a `-t "a|b"` filter is a pipe:
   run Vitest as `node node_modules/vitest/vitest.mjs run …` with no shell.
2. **jsdom's global `URL` is jsdom's**: `fileURLToPath(new URL('../x', import.meta.url))` throws "must be of
   scheme file" in a jsdom test; use `resolve(dirname(fileURLToPath(import.meta.url)), '../x')`.
3. **A heredoc appended to a CRLF file adds LF lines**; the plant runner then misses a multi-line find. One
   ending per file (the scratch `crlf.cjs`) before planting.
4. **R.A.B.B.I.T.'s kit-fight guard (`rabbitCssGuards.js` `kitFights`) reads every kit rule against every
   lane's Panel by class**, attributes aside: a kit rule on `.ui-panel[…]` that sets a property a lane's
   `.ui-panel.rb-…` rule sets is a tie it refuses. Only the full run shows it; `:where()` weighs nothing.
5. **A picture script's parked pointer is a hover**: on a scrollbar it turns the thumb orange; park it on the
   orange header (`W / 2, 30`).
6. **The plant runner edits the source the dev server serves**, and a page open in the pane keeps the old
   console messages: judge errors on a fresh page (`scratchpad/measure/console-check.mjs`).
7. **The integration branch moved twice under the session** (AT1's merge, then its answers): two merge-ins,
