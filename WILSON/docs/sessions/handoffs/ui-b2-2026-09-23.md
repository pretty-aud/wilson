## 5. Traps hit

1. 🚨 **THE BASH TOOL COLLAPSES `\\` TO `\`** (B1's trap 1, again). It broke
   `node -e` one-liners and heredoc regexes several times. A heredoc of
   prose with many apostrophes also failed to parse. Write scripts and prose
   through the Write tool, and use `String.raw` for regexes in scripts.
2. 🚨 **THE WORKING COPIES ARE CRLF.** A naive `split(a).join(b)` on an LF
   literal matched nothing. B2's edit scripts normalise to LF, count the
   matches (exactly one) and write the file's own line endings back.
3. ⚠️ **IMPORTING A TEST FILE RUNS ITS SUITE TWICE.** B1's scanners had to
   move to a module (`rabbitCssGuards.js`) before B2 could import them. The
   type-scale audit then read the module's regex literals as class names,
   hence the `EXCLUDED` entry.
4. ⚠️ **THE WALK COUNTS A `visibility: hidden` BUTTON AS UNNAMED.** The key
   date's hover-only delete needed an `aria-label`.
5. 🚨 **A `mountedRef` SET ONLY AT ITS DECLARATION BREAKS UNDER STRICTMODE.**
   The second mount's cleanup leaves it false, and every async result is
   dropped. Set it true inside the effect.
6. 📌 **PLAYWRIGHT DRAGS FROM THE ELEMENT'S CENTRE.** A row's centre is a
   `<select>`, so the drag never started. Pass `sourcePosition` on the title
   cell.
7. 🚨 **REACT COMMITS BETWEEN TWO DOCUMENT LISTENERS; JSDOM DOES NOT.** K4's
   first version asked `overlay.js` how many menus were open. In a browser
   the Menu had already unmounted when the Dialog's listener ran, so the
   count was 0 and the Dialog closed too. Every jsdom test passed. Use the
   event's own mark (`preventDefault` / `defaultPrevented`), which travels
   with the event.
8. 🚨 **THE KIT DIALOG CLOSES ON BACKDROP `mousedown`, BEFORE THE FIELD
   BLURS.** A save-on-blur editor was unmounted with its edit (round one's
   blocker). K5 blurs first.
9. ⚠️ **THE KIT MENU CLOSES ON CAPTURE `mousedown` AND LETS THE CLICK
   THROUGH.** A picker built on it pressed whatever was under the dismissing
   click. B2 hand-rolled the picker with a scrim (K6).
10. ⚠️ **THE SCANNERS CANNOT SEE ATTRIBUTES A KIT PROP SETS.** For example,
    `Row selected` sets `data-selected`, and a presence-only selector is
    banned by `dataState.test`. Write the data attribute explicitly in the
    JSX, or use a structural selector (`nth-last-child`).
11. 🚨 **A MOCK THAT IS NOT THE REAL ELEMENT HIDES THE BUG.** Round one's
    FileManager mock rendered a `<textarea>`, and the fix keyed on TEXTAREA.
    The real notes editor is an `<input type="text">`, so the popup closed
    in the app while the test passed. Round two found it in the running app.
    Read the real element before you mock it.
12. ⚠️ **A STICKY CELL NEEDS AN OPAQUE GROUND** (the kit's R06, again). The
    translucent drag-over tint let the covered task row's text read through
    the stuck header. Lay the tint as a `background-image` over the paper
    token.
13. ⚠️ **ENTER ON A BUTTON NEVER REACHES IT** (§4, Foundation). Verify
    keyboard activation with Space, or you will measure the companion.
14. 📌 **`.claude/launch.json` IS TRACKED** (B1's trap 2): set the local
    entry aside for a merge, re-add it, and re-prove the server with a
    marker.
15. 📌 **THE DASHBOARD'S POPUP IS THE SAME COMPONENT.** Every popup change
    was re-checked there: the veto's stacked question, Escape order and the
    reading width.
16. 🚨 **A MUTATION COPY MUST NOT JUNCTION `node_modules`.** Round one's
    guard reviewer copied the repo into the scratchpad and junctioned its
    `node_modules` to this worktree's. A recursive delete of that copy
    would have gone through the link and emptied the worktree's packages.
    Round two's reviewer flagged it. The link itself was removed with
    `cmd /c rmdir`, which leaves the target alone, and the packages were
    checked afterwards. Tell a reviewer subagent to copy `node_modules` or
    to run its harness on the worktree, never to link it.
17. ⚠️ **AN EDIT DURING A WALK HOT-RELOADS THE PAGE UNDER IT.** Vite's HMR
    reloaded the app partway through a walk when a source changed. Finish
    the walk first. A mutation run on the live worktree is the same:
    `mutate.mjs` exits on a concurrent edit, by design.
18. ⚠️ **SHARPENING ONE CHECK CAN BLUNT ANOTHER.** Teaching the scope check
    to keep `:is(a, b)` whole let `:is(.rb-task-view, .ui-dialog) .x`
    through. The old comma split had caught it by accident. Re-run the
    previous round's KILLED list after any guard rewrite, not only the
    survivors.
