## 1. The row contract

Plan §5 D1: *"label left at the 11px Label step, control right, one column,
one 36px row height, hairline between rows, section titles at 16px, group
gaps from the spacing scale."* Made exact, and applied to every section of
every tab without exception:

| Part | Rule |
|---|---|
| **Column** | One. Every control is a full-width row inside the 720px reading measure (`--width-reading`). No two-column forms, no side-by-side control pairs. |
| **Row box** | `min-height: 36px` (`--row`), flex, `align-items: center`, `justify-content: space-between`, `gap: 16px`, `padding: 8px 0`. A row with a description grows; the control stays centred on the label's first line. |
| **Label** | Left. The **Label step**: 11px / 600 / UPPERCASE / +0.06em (`text-label`), ink `#1c1917`. Field labels keep uppercase — this is the one surviving uppercase role (Q2; critic resolution 8 rejects O25's case change). |
| **Description** | Optional, directly under the label inside the left cell. **Caption step**, 12px / 400 / sentence case, ink `#1c1917`. Never uppercase, never tracked, never bold. |
| **Control** | Right. From `src/ui/` only. `sm` (28px) inside dense groups, `md` (36px) for a section's own primary action and for text inputs. |
| **Hairline** | `border-top: 1px solid var(--color-rule-light)` on every row except the first of its group. No boxes around rows, no fills, no zebra. |
| **Section title** | **H2**, 16px / 600 / sentence case, hairline above, 24px clear below the previous group. Optional Dense (13px) description under it, capped at 72ch. |
| **Card title** | **H3**, 14px / 600 / sentence case — an object heading *inside* a section (critic resolution 6: 16 is the region, 14 is the object). |
| **Eyebrow** | Label step, used to name a group of rows inside a section. This is the S14 reframe (§4). |
| **Group gaps** | 24px between groups, 8px within a group. Both from the spacing scale; nothing else. |
| **Primary** | Exactly one filled primary per region: `signal-fill` `#c2410c` with white (5.18:1, Q16). Everything else is secondary or ghost. |
| **Status on light** | Never colour. Q1 Option A gives the light pages one ink; status is the written word plus a dot in `#1c1917`. The six-value pet ladder, the two pastel chips and the green/red migration counts all resolve to this. |

**Surface rules that bound the contract.** Settings stays on `#f4a261`
(Q1 Option A, C9). `#1c1917` is its only ink (C6: white on `#f4a261` is
2.06:1). Raised surfaces are `well-light` `rgba(120,70,30,0.18)`; opaque
floating panels are `surface-light-solid` `#dd9155`. **No white, cream or
pale grey anywhere** — that retires `hover:bg-red-50`, `hover:bg-stone-100`,
`hover:bg-stone-200`, `hover:bg-stone-300`, `#dcfce7`, `#fee2e2` and
`text-stone-100` from this surface. **No dark island on the light page**
either: the `#1c1917` textareas, the `bg-stone-900` log wells and the
`#1c1917` select in `CurrencyPicker` become light-surface wells.

restyle written next to a surviving inline style silently drops the state

     two-state buttons with `data-on` until the track has a light rule.

     after the light rule at equal specificity, so it resolves to `ink-3`
