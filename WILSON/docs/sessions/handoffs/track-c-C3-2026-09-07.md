## 5. Traps hit

- 🚨 **A MEASURED DIFF IS ONLY EVER ACCURATE ABOUT WHAT IT MEASURED, AND IT
  WILL BE READ AS A STATEMENT ABOUT THE FEATURE.** The §6 #31 polarity diff ran
  in two halves — the legacy reader across revisions, and a legacy project
  through the real migration and back — and both were ZERO, correctly. Neither
  covered the WRITE path, which is where this bundle had actually moved the
  flip: the Resources drop zone wrote `isCoreDefiner: false`, so a brief
  dropped on Local Server went from CORE to REFERENCE with nothing failing.
  Review round 1 found it. Write down what a diff does NOT cover, next to the
  diff.
- 🚨 **THE DEFECTS BOTH ROUNDS FOUND IN MY OWN WORK WERE ALL COMMENTS THAT
  ASSERTED THE OPPOSITE OF THE CODE.** Round 1: "this matches what the legacy
  writer already wrote" (it wrote a key nothing read). Round 2: "RABBIT's own
  uploads leave `document_kind` NULL, and that is what keeps plates out" (true
  of documents, false of media, in three places at once) and a paragraph about
  intake that was called "measured" and had never been traced. The code was
  green for all of it. **When a comment explains WHY something is safe, that
  sentence is the thing to verify, not the line under it.**
- 🚨 **A BREAKER THAT SILENTLY STOPS BREAKING IS WORSE THAN NO BREAKER.**
  See §3.2. The failure mode is that a re-run reports the probes passing, which
  is indistinguishable from probes with no teeth.
- 🚨 **A PROBE CAN BE UNABLE TO FAIL BECAUSE OF THE ROLE THE SUITE RUNS AS.**
  Probe 16 counted `information_schema.column_privileges` for grantee `anon`,
  from a session that had `SET LOCAL ROLE authenticated` nine probes earlier —
  and that view hides rows granted to anon by postgres from any role that is
  neither. `has_table_privilege` / `has_column_privilege` are role-independent.
  Suite 77's own round-1 note says the same thing about `role_table_grants`;
  the lesson had to be learned twice.
  ⚠️ And the two are NOT interchangeable: a COLUMN grant does not set the table
  bit, so `has_table_privilege` alone still could not see breaker B9.
- 🚨 **AN UPDATE PASSES THE SELECT POLICY TOO, so a money arm on `files_update`
  is not independently observable from a client.** Round 1 asked for a
  behavioural negative twin; building it and measuring it (breaker B10) showed
  the member's write affects zero rows even with the arm dropped, because the
  UPDATE's WHERE clause reads the row. The instrument for that arm is
  structural, and it has to count PER CLAUSE — `qual OR with_check` cannot see
  `files_update` losing one of its two (breaker B11).
- **A fix can open the hole it closes.** Round 1 made D.O.G. spend its budget
  documents-first so media could not crowd out the brief; `documentKindFor`
  then labelled an extension-only `.mov` a *document*, and one clip could take
  the whole budget by jumping the queue. `File.type` is the empty string for
  .mov/.mkv/.avi — S40's lesson, restated four lines away in the same file.
- **Fixing a race by reordering can turn a visible failure into a silent one.**
  Round 1 moved the create-modal's selection after the uploads to stop an
  effect erasing the error; an upload rejection then skipped the selection
  entirely, and the error rendered inside `{selectedProject && …}`. The fix for
  a race is a state the racer does not write, not a different order.
- **`ADD COLUMN IF NOT EXISTS` + `--workdir` + an applied migration**: re-apply
  is a no-op, which is right for the migration and wrong for anything that
  reuses its text.
- **The desktop Bash tool mangles `\\r\\n`, `\\s` and `\\b` inside heredocs.**
  Every regex or line-ending literal in a patch script must go through a file
  written with the Write tool, not a heredoc. This cost several attempts, and
  once **truncated a 5 700-line source file to zero bytes** (an `io.open(...,
  'w', newline='\\r\\n')` whose argument had been mangled — `open` validated
  the newline value after truncating). Recovered by `git checkout --` and
  replaying the patch scripts, which is the reason to keep them as files.
- **A vitest source pin can keep a dead symbol alive.** `storedFilesReloadKey`
  lost both its writers in the commit that added it; the dependency-array
  assertion held the identifier in place where no linter would look.
- **`tap-all.mjs` buffers when piped** (C2's lesson): `| tail -30` produced 15
  dots and exit 0 with no summary. Redirect to a file.
- **`gh` is not authenticated on this machine**; CI has to be read by URL.
