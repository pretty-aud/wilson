## 5. Traps hit

1. 🚨 **`ch` IS RESOLVED IN THE FONT OF THE ELEMENT THAT USES IT.** One
   token, `--measure-body: 45ch`, was 418px on a paragraph, 492px on a 16px
   heading and 615px on the 20px title. A shared edge needs the token
   resolved ONCE: a registered `<length>` (`@property … { syntax: '<length>
   | none'; inherits: true; initial-value: none }`), declared only in a rule
   that sets the Body step, inherited as px. `none` as the initial value
   means an unset use caps nothing instead of collapsing to 0.
2. 🚨 **`ch` IS THE ZERO, AND GEIST'S ZERO IS WIDE.** 0.663em (9.28px at
   14px) against an average glyph of ~0.47em, so "60–66ch" is 86–95
   characters, not 60–66. Measure characters per line on real prose (a
   range per character, grouped by line box) before trusting a `ch` value.
   (`4b4edc5`'s message says 0.673em / 9.42px; the comment is corrected.)
3. 🚨 **A UTILITY BEATS THE `components` LAYER, SO A STATE MUST MOVE WHOLE.**
   Extracting the card's border colour but leaving the `border` utility drew
   the dashed branches solid (the utility also sets the style). Move every
   property a state touches.
4. 🚨 **TWO COLOUR UTILITIES ON ONE ELEMENT: THE LATER-EMITTED WINS, NOT
   THE TERNARY.** The row menu's open branch (`text-orange-400` beside
   `text-stone-400`) was dead for months. Measure a state before
   transcribing it; transcribe what rendered.
5. 🚨 **`cmd | grep | head && git commit` COMMITS ON A RED SUITE.** The
   pipeline's status is `head`'s. It happened once here (A3-KR-6, a pinned
   Chip test); the commit was unpushed and was amended with the test's
   update and its mutant. Gate commits on vitest's own exit code.
6. ⚠️ **A GRID DOES NOT COLLAPSE MARGINS.** Parts spaced by margins in block
   flow double-count in a grid (16px under a name, a 25px inset); space a
   grid by its `row-gap`. And separate lists only share columns as subgrids
   of one grid (the node card), not as sibling grids with `max-content`.
7. ⚠️ **A PROBE THAT APPENDS INTO A FLEX CONTAINER MEASURES A FLEX ITEM.**
   Round two's probe read the node badge 3.5px off its row's baseline; an
   inline probe inside the badge's text measured 0.0 with the label's
   `overflow` either way. Measure a baseline from inside the text's own box.
8. ⚠️ **IN-PLACE MUTANTS AND HOT RELOAD.** A reviewer mutating the source
   in place leaks every mutant into any page another reviewer is measuring
   (Vite pushes it). Round two's guards reviewer worked in a scratch copy of
   the tree; the measuring reviewers checked `git diff --stat` around every
   run.
9. ⚠️ **`getComputedStyle` DURING A TRANSITION RETURNS THE OLD VALUE.** A
   forced attribute read immediately reads mid-transition. Wait out
   `transition-colors` (150ms) before reading.
10. ⚠️ **EVERY PAGE STAYS MOUNTED.** `document.querySelector('main')` and
    `'textarea'` found D.O.G.'s hidden ones; O.T.T.E.R.'s main is
    `#otter-view-panel`'s parent. Scope probes to visible elements.
11. ⚠️ **A KIT MENU AND A TOGGLE TRIGGER.** The kit Menu closes on a
    capture-phase mousedown outside itself — the trigger is outside, so the
    click that follows reopens it. Record the open state on `pointerdown`
    and swallow that one click.
12. ⚠️ **INHERITED CAPITALS.** The kit Chip's count zeroed its tracking but
    inherited `text-transform: uppercase` (A3-KR-2).
13. ⚠️ **ONEDARK'S STYLES ARE INLINE, AND REACT-MARKDOWN WRAPS EVERY FENCE
    IN ITS OWN `<pre>`.** Neutralise the highlighter's box through
    `customStyle` (and make it as wide as its code, or a scrolled line loses
    its end padding); change a token colour in a copy of the theme object;
    passing `codeTagProps` replaces the default, so give it the
    `language-x` className yourself.
14. 📌 **THE BASH TOOL'S SHELL STRIPS BACKSLASHES** from `node -e` strings
    and even quoted heredocs (`\(` arrived as `(`). Write any script that
    carries a regex with the Write tool and run the file.
15. 📌 **A SPEC WHOSE FIND SPANS A LINE BREAK MUST MATCH THE FILE'S EOL.**
    The CSS and JSX are CRLF in the working tree, `scripts/*.mjs` LF.
16. 📌 **RE-INDENTING A WRAPPED BLOCK BURIES THE CHANGE.** Wrapping `<main>`'s
    views in a tabpanel re-indented ninety lines; the second attempt left
    them where they were (Track A merges into this file later).
17. 📌 Fixtures: no stub subject, no node system, no coding-language course,
    no metadata-only course, no code fence, no long heading. Round two
    rewrote the fixture file in flight (`page.route`) to put real data
    through the app's own markdown and highlighter.
