## 5. Traps hit

1. 🚨 **A DOM CHECK CANNOT SEE A DIALOG THAT HAS JUST CLOSED.** The kit's
   Drawer guarded Escape with `document.querySelector('.ui-dialog')`. The
   Dialog listens on `document`, the Drawer on `window`; in a browser React
   commits the Dialog's close in a microtask that runs BETWEEN the two
   listeners, so the Drawer found no dialog and closed too — one Escape, two
   layers gone. A scripted `dispatchEvent` runs no microtask between listeners,
   so the unit test was green. Use `e.defaultPrevented` (a layer marks the key
   it owns), and reproduce the browser's order in a test with `flushSync` in
   the closing handler.
2. 🚨 **THE SWEEPS READ COMMENTS.** `typeScale.test.js`'s one-border sweep
   treats a comment that names `border-l-2` as a live site (the full suite went
   3084 / 3085 on it); the plain `ui-audit` counts comment hits too. Describe a
   retired utility in words in a comment, never by its class name or hex.
3. 🚨 **`scripts/*.mjs` ARE LF; EVERYTHING ELSE HERE IS CRLF.** An edit helper
   that normalises a file to the working tree's CRLF wrote CRLF into
   `ui-walk.mjs` (`.gitattributes` has `eol=lf` for them — the brief's "one
   fewer file" trap). Keep each file's own endings; check with
   `git ls-files --eol`.
4. ⚠️ **A KIT CONTROL THAT MARKS A KEY HANDLED MEETS A PAGE HANDLER THAT DOES
   NOT ASK.** The kit Tabs `preventDefault` their arrow keys; D.O.G.'s
   document-level ←/→ page switcher ignored that and switched the page behind
   the dialog on the same press. Any tool with a document-level key handler
   should check `e.defaultPrevented` before a kit control lands inside it.
5. ⚠️ **THE KIT'S TABS ARE CONTENT-WIDE.** Replacing two `flex-1` buttons with
   kit Tabs left three quarters of the strip dead to a click (C1). Stretch the
   tabs where the old strip was split in halves.
6. ⚠️ **Z-ORDER IS A CONTRACT NOW.** The kit's layers: Drawer backdrop 59,
   Drawer 60, Dialog 70, Menu 80, Toast 90. A page's own floating element must
   sit under 59 unless it is an overlay; D.O.G.'s rewrite preview was 80 and
   floated over Help once Help moved from z-100 to the kit's 70.
7. ⚠️ **A POPUP RENDERED INSIDE A DIALOG STAYS FIXED TO THE VIEWPORT** only
   because nothing between it and the viewport transforms (the backdrop's fade
   is opacity only). If the kit ever animates the Dialog with a transform, the
   resolver's C4-pinned preview moves.
8. 📌 **`<label htmlFor>` IS A NEW CLICK TARGET.** A1's field labels are
   unassociated; name a field with `aria-labelledby` to announce it without
   making its label clickable (C1).
9. 📌 D.O.G.'s dev fixtures run in cloud mode, so New project shows the cloud
   note, not the pickers; photograph the local branch by forcing it and
   reverting.
10. 📌 `.env.local` aside restarts Vite without it (A1's trap 6) — restart the
    server after the no-env suite run.
11. ⚠️ **A FIX MEASURED ONLY AT ITS FAILURE CASE CAN BREAK THE CASES THAT
    WORKED.** The first Menu clamp was checked where the bug was (the bottom
    edge) and placed every menu as if it were 160px, so short menus that
    fitted jumped up. Test the control cases too, and prove the new test
    fails on the old code (A2 ran both its Menu versions against the final
    tests).
12. ⚠️ **TWO LANES FIXED THE SAME KIT HANDLER THE SAME DAY.** B2's K4 and A2's
    KR-3 both taught `Dialog`'s Escape to use the handled mark; B2 merged
    A2's first and combined them. Fetch before a kit fix and read the other
    lane's commit before writing your own.
