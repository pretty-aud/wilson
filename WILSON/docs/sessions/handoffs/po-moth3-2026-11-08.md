## 5. Traps hit

- **The editor's Yjs binding deletes any node or mark its schema does not know** (`@tiptap/y-tiptap`'s
  createNodeFromYElement and createTextNodesFromYText), and the deletion is saved: a mention node would be erased the
  first time an older build opened the note. A note's typed link is text, drawn by a decoration.
- **A policy that leaves a row out says nothing**: a refused change of the company standard read as "no row" (a
  silent 0 rows, PGRST116, or saveWithMerge's retries). The owner stays in the policy; the guard refuses in words.
- **`FOR UPDATE` against a person's foreign key check**: a merge holding the tags FOR UPDATE while its fold waited on
  an inserter's advisory lock was a deadlock; FOR NO KEY UPDATE lets the key check through.
- **A CASE inside a PL/pgSQL IF needs parentheses**: the parser takes the CASE's THEN for the IF's.
- **Suite helpers run as the test, not as a client**: `tests.login_as` after a forged token needs `RESET ROLE` first;
  a client inserts no id (no column grant), so fixtures that need an id are made by the test.
- **The Moth folder is a lazy chunk**: nothing outside it may import from it; shared rules go to R.A.B.B.I.T.'s
  state folder (MothPage.test.jsx scans it).
- **An id with no letters has no capitals**; **SQL does not short-circuit a cast** (use to_regclass on both sides);
  **a grep for a carriage return is no line-ending test here** (ask Python); **a later REVOKE line matches a function
  name first** (look for CREATE OR REPLACE).
- **Four vitest workers fail a loopback test now and then on this PC**: read the failure and run the file alone.
- My slips against her rule: a quoted heredoc twice (one a fix, one a read-only summary), and short `python -c`
  payloads; payloads go through the Write tool.
- **Every row of one test transaction shares its moment**: a probe's newest row takes the reader's own order
  (`WITH ORDINALITY`), never `observed_at`.
- **A side with no project is read by its class alone** ('workspace' for the company's members, 'personal' for its
  owner); Moth's project gate has nothing to say about it, and asking it refused the owner.
- **A window by a fixed list of types** missed a company made after the migration: the list is the types, not the
  marks.

- **A purge's own capture runs before its foreign keys' cascade** (seen on wilson-dev: the note's delete row has the
  lower id): a cascaded tagging or link finds its gone end's last row already written, and a file that locks on its
  purge blanks its live taggings and links before the cascade takes them.
- **A private project is read by its creator and admins only** (0082's privacy arm), never by its members: a probe of
