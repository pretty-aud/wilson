## 5. Traps hit

- **The editor's Yjs binding deletes any node or mark its schema does not know** (`@tiptap/y-tiptap`'s
  createNodeFromYElement and createTextNodesFromYText), and the deletion is saved: a mention node would be erased the
  first time an older build opened the note. A note's typed link is text, drawn by a decoration.
- **A policy that leaves a row out says nothing**: a refused change of the company standard read as "no row" (a
  silent 0 rows, PGRST116, or saveWithMerge's retries). The owner stays in the policy; the guard refuses in words.
- **`FOR UPDATE` against a person's foreign key check**: a merge holding the tags FOR UPDATE while its fold waited on
  an inserter's advisory lock was a deadlock; FOR NO KEY UPDATE lets the key check through.
- **A CASE inside a PL/pgSQL IF needs parentheses**: the parser takes the CASE's THEN for the IF's.
- **Suite helpers run as the test, not as a client**: `tests.login_as` after a forged token needs `RESET ROLE` first;
  a client inserts no id (no column grant), so fixtures that need an id are made by the test.

  state folder (MothPage.test.jsx scans it).
