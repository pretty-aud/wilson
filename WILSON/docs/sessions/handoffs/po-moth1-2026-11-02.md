## 5. Traps hit

- 🚨 **A Windows path in a doc broke the web build.** Tailwind v4 scans every tracked file for class names, docs included, and decodes a backslash followed by hex digits as a CSS escape: in the scratchpad path, a backslash before `8de41a…` is past U+10FFFF, so `String.fromCodePoint` threw ("Invalid code point 9298970") and `vite build` failed. CI's Playwright job builds the web app for its preview server, so it failed from `b1be86e2` (the final design, which quoted an agent's scratch path) to `146e94f5`; the beta's build would have too. Fixed by removing both paths; never write a backslash path into a tracked file. Six older backslash-hex strings in tests, 0091, suite 93 and an old hand-off do not trip it (the build passed with them), so the trigger depends on the token around it: do not rely on that.
- 🚨 **A probe that names its row by id is judged by the SELECT policies too**, so it cannot show a USING hop: Postgres applies SELECT policies whenever an UPDATE or DELETE reads a column. Only a blanket write (no WHERE, no column read) reaches USING alone; give it a public-row control that proves it ran. Six of suite 110's first probes were inert this way; plant P2 found it.
- 🚨 **BEFORE triggers run before RLS.** A definer guard that answers "another project" for a wrong id while RLS refuses a right one is an existence oracle over hidden ids; the guard must judge only rows the caller could reach. Suite 44's probe 10 found it in the whole-set rehearsal.
- A later migration that restates a policy breaks every earlier suite that pins its whole text (90, 95) or depends on its old refusal order (54, 83): run the whole set with the migration prepended before applying anything.
- `phases` has no `workspace_id`; a client-created project's creator is seated by 0020's auto-staff trigger, so a fixture seat duplicates it.
- A bash heredoc holding a Python script with backslashes failed to parse; scripts go through the Write tool, as the house rule says. `python -I` ignores `PYTHONIOENCODING`: call `sys.stdout.reconfigure(encoding="utf-8")`. Git Bash rewrites `git show <ref>:.claude/…`: prefix `MSYS_NO_PATHCONV=1`.
