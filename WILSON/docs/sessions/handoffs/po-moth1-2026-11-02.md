## 5. Traps hit

- 🚨 **A Windows path in a doc broke the web build** (Tailwind v4 decodes a backslash and hex digits as a CSS escape). Never write a backslash path into a tracked file.
- 🚨 **A probe that names its row by id is judged by the SELECT policies too**; only a blanket write reaches USING alone.
- 🚨 **BEFORE triggers run before RLS**: a definer guard judges only rows the caller can see.
- 🚨 **A statement-level AFTER DELETE trigger fires BEFORE the cascade's child rows are captured** (0108).
- 🚨 **`created_at` is the transaction's start, not the write's order**: one entity's history is ordered by id.
- 🚨 **Suites 94, 99 and 101 count each quoted table name in `fn_realtime_broadcast` exactly once** (comments stripped): a restatement that names a table twice (a second CASE, a literal `'projects'` in a payload) fails all three. Resolve both sides in one CASE.
- 🚨 **0107's `topic_epoch` arrives before 0109's senders**: a client must not join an epoch topic until 0109 is present (the adapter probes `project_topic_matches`).
- **`db query` drops RAISE NOTICE**: a rehearsal that must record a NOTICE's numbers measures them itself with a final SELECT before `ROLLBACK;` (the API returns the last statement's rows).
- **`projects.id` and `files.id` are the client's to send**: anything keyed by a past project or file id must survive the id being created again.
- **`supabase db reset` drops pgtap** (`supabase test db` installs it only for its own run).
- **A cloud worker restart kills the Docker daemon** (and the local stack with it).
- A later migration that restates a policy or a body breaks every earlier suite that pins its text or its md5: run the whole set before committing (0109 needed 100 and 101's md5 and the one-name-once rule).
- Scripts with backslashes or regexes go through the Write tool, never inline in the Bash tool (its quoting ate two of this session's).
- 🚨 **A vitest pins suite plans**: `src/lib/localMediaWiring.test.js` reads suite 80 and pins its `SELECT plan(N)`. `eccd1d2e` changed no client code but moved suite 80's plan, and CI's Vitest went red; run the whole vitest suite after any suite edit too.
- 🚨 **A route body in `electron/main.cjs` may be lifted by a test**: the project PATCH's is, by three files (`extractRouteBody`), so a guard written inside it throws "personalSpace is not defined" there. A guard that runs ahead of a route goes in the route's own module, mounted before it.
- **The whole vitest set under other load fails unrelated timing tests** (2026-11-04: dozens in the Timeline, Scenes and D.O.G. render files, every one green alone). Re-run before reading a failure as yours.
- Cost: one review round as a small workflow (13 agents) took about 22 minutes and most of a percent of the week; building in the main loop is cheap by comparison.
