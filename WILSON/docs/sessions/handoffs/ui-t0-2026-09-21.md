**The rules that are not the naive rule, each with what it cost to learn:**

1. **A control is a control.** 241 `uppercase` sites are on `<button>` and 34
   on `<select>`. The kit rules those (`.ui-btn` 14/600/sentence, `sm` 13,
   `.ui-input` 13/400) and §3.1's Label job list has no control on it.
2. **A heading tag is a heading**, whatever size it was written at. This
   codebase writes section headings as `<h3 className="text-sm font-bold
   uppercase">`, so a size-only rule sent 54 heading tags to the 11px floor and
   left them SMALLER than the body beneath — D.O.G.'s help pane had 15 `<h3>`
   at 11px over 47 `<h4>` at 13px.
3. **A shouting sentence is a sentence.** `uppercase` with forty characters
   behind it is prose set in capitals, not a label.
4. **The size cliff is at 18, not 16.** At 16 it split one designed pair of row
   labels in R.A.B.B.I.T.'s cost breakdown.
5. **`stone-400` is not metadata.** F1's ladder maps stone-300/400 to **ink-2**,
   the secondary BODY ink, and stone-500/600 to ink-3.
6. **`font-medium` is not a heading.** 500 sits on body copy as often as on
   structure; it classified D.O.G.'s red error banner as a heading.
7. **Tracking is not evidence of a label.** Of the 855 sites the tracking arms
   caught, 853 carried `uppercase` anyway, and the one they decided alone they
   decided wrong. Capitals are a statement about what the text IS; tracking is
   a nicety an author reaches for on anything small.
8. **A prose tag outranks a dim ink.** `<p>`, `<ul>`, `<ol>` join `<td>` and
   `<li>`: without them two paragraphs of the same kind in one help card landed
   on Dense and Caption, and 13px beside 12px reads as a rendering fault.
9. **A conditional class is not evidence about every branch.** Pass 1 ignores
   ternary arms; pass 2 and the guard still read them, because "does this carry
   a step at all?" is a different question.
10. **The muted ink is written inline too.** R.A.B.B.I.T. writes
    `style={{ color: '#78716c' }}` where D.O.G. writes `text-stone-500`, so the
    Caption step was unreachable there — **0 Caption sites in R.A.B.B.I.T.
    before, 30 after**.

## 5. Traps hit

1. 🚨 **"Prove the server serves your worktree" is harder than it looks.** C3c's
   recipe (`curl …/src/ui/Table.jsx` must return a module, not `<!doctype
   html>`) proves a Vite server is answering — it does **not** prove WHICH
   checkout. Every worktree has `src/ui/Table.jsx`, and grepping the served CSS
   for a design-system string finds it in every checkout since F1. The only
   check that discriminates is a string **only your worktree has**: write a
   throwaway file into `src/`, fetch it, delete it.
2. 🚨 **`/…\]\b/` DOES NOT MATCH `text-[12px]"`.** `]` and `"` are both
   non-word, so there is no boundary between them. The arbitrary-size arm
   matched **nothing** and the first inventory reported 706 sites instead of
   2,584. It looked like a plausible number. **This trap recurred twice more**:
   in `font-…|\[\d+\])\b` and `border-…|\[[^\]]*\])\b` in the guard, where the
   guard's own controls caught it. Put the `\b` on the word alternatives only.
3. 🚨 **A class name is not always a class.** `dogHelpContent.jsx` carries
   D.O.G.'s help-page light theme as an embedded stylesheet whose selectors
   name the very classes the codemod rewrites. Rewriting one unhooks the
   override; **protecting it and walking away is just as broken**, because the
   selector then points at a class that no longer exists. Pass 1 protects the
   stylesheet AND re-points its three selectors, inside the pass, so a
   clean-tree re-run reproduces it.
4. 🚨 **An unmatched `<style>` must protect NOTHING.** A `//` comment in
   `NotesView.jsx` mentions a `<style>` element and the file has no `</style>`,
   so the scanner protected to end of file: **787 of 821 lines invisible** to
   the passes AND to every assertion. It failed silently and in the
   safe-LOOKING direction, which is what made it dangerous. (The practical
   damage was nil — lane C2 had already converted that file — but the blindness
   was real.) The `<style>` scan must also run over comment-blanked source.
5. 🚨 **An apostrophe in JSX prose desynchronises a naive string scanner.** A
   quote that OPENS a string never directly follows a letter or a digit; one in
   prose almost always does.
6. 🚨 **"The class list" is three different questions.** `enclosingRun` went
   through four versions. A token in a template literal must see the whole
   template (or `${small ? 'text-dense' : …} uppercase` hides its own
   evidence). But a token OUTSIDE every `${…}` must NOT see the arms, or a
   class only phase bars get decides every task bar. And "does this site carry
   a step at all?" must see the arms again, because a step inside one is still
   a step. Pass 1 uses the stripped run; pass 2 and the guard use the raw one.
7. 🚨 **An evidence window is a parser you did not write.** Three attempts, and
   the first two each broke R.A.B.B.I.T.'s money: text-to-next-`<` is empty for
   a wrapper; a fixed 420-character window reads the NEXT block's code; and
   stop-at-first-`</` stops at the first CHILD's close, so a six-column row is
   judged on its name column. Walk to the MATCHING close, and harvest `{…}`
   from self-closing children's props — `<CurrencyDisplay value={x} />` is the
   only expression there is.
8. 🚨 **F4's trap 4, three times, on my own guard.** `git checkout <sha> --
   src` to re-run a pass from a clean tree ALSO reverts
   `src/ui/typeScale.test.js`, because the guard lives in `src/` too. It cost
   two rewrites. **Commit the guard before re-running any pass**, or keep the
   guard outside `src/`.
9. 🚨 **F4's trap 3: node's `/tmp` on Windows is `C:\tmp`, Git Bash's is not.**
   `curl -o /tmp/x.json` then `node -e "readFileSync('/tmp/x.json')"` fails
   with ENOENT on a file curl definitely wrote.
10. 🚨 **`git checkout <sha> -- src` STAGES what it restores.** The index then
    holds the old tree while the working tree holds the new one, and
    `git status` shows `MM` on 70 files. `git reset HEAD -- src` after every
    such checkout, or the next commit is not what you think it is.
11. 🚨 **Do not run adversarial mutant reviews in a worktree you are still
    writing to.** A reviewer's planted mutant and my own uncommitted work
    collided twice: once its mutant appeared in my `git diff` and once my edit
    appeared in its restore. Both were caught, but a `git diff` taken while a
    mutant reviewer runs is not evidence about anything.
12. ⚠️ **A guard that reads the tree can break other tests without failing
    itself.** Six uncached sweeps over 271 files pushed four unrelated
    tree-walking tests past their 5s timeout under vitest's parallel workers
    and tripled the suite's wall clock — while passing in 1.5s alone. Cache it.
13. ⚠️ **A control that re-types its assertion's regex proves nothing.** A
    reviewer narrowed the border assertion to `/\bborder-[9]\b/`, planted a
    real `border-4`, and the suite stayed green **with the control passing**.
    One named const, used by both.
14. ⚠️ **An assertion that names a utility must anchor on the utility ROOT.**
    `border-2` was silent over 102 live `border-b-2`; `text-…3xl` over a
    `text-6xl`; `rounded-sm` over `rounded-t-sm`.
15. ⚠️ **`\btext-label\b` matches inside `var(--text-label)`.** `-` is
    non-word, so the boundary is there. The lookbehind is load-bearing.
16. ⚠️ **Timeline and Files both open on an EMPTY STATE**, and App.jsx renders
    EVERY page at once (so a Playwright locator resolves against a control on a
    page nobody is looking at — F4's trap 7 on another surface). The first two
    screenshot runs captured "No project selected" at both sizes and the PNGs
    looked plausible.
17. 🚨 **A SCANNER THAT STARTS INSIDE AN ATTRIBUTE HAS ITS QUOTES INVERTED.**
    Finding the opening tag's real `>` (rather than `indexOf('>')`, which lands
    inside an `onClick={() => …}`) needs a quote-aware scan — but the scan
    begins at a CLASS TOKEN, which is inside `className="…"`, so it reads that
    value's CLOSING quote as an OPENING one and every quote after it is
    inverted. Unhandled, it emptied nearly every element body and pass 3
    dropped 1,552 of 1,601 mono sites instead of 1,276. Step over the rest of
    the current attribute value first.
18. 📌 **Measure a threshold, do not pick one.** The shouting-sentence rule
    started at "more than 30 characters" and split one panel's eleven sibling
    eyebrows between 30 and 32. Dumping every `uppercase` site with the length
    of its own text showed the two populations plainly: real labels stop at
    seven words, real sentences start at ten, and nothing sits at eight or
    nine. The line goes where the data has a gap.
19. 📌 **The brief says "eight scale steps"; the shipped `@theme` has SEVEN**
    (h1, h2, h3, body, dense, caption, label). Plan §3 says "Type steps: 7" and
    plan §5 says "the 8 steps" — the plan disagrees with itself and the CSS
    wins. There is no Display step; the transition title's 16.8px is inline and
    exempt (Q18).
