(12/14/16/18/20/24/30).

**Five rules in that table are not the naive rule, and each one is there because
the naive rule was measured and found wrong:**

1. **A control is a control.** 241 `uppercase` sites are on `<button>` and 34 on
   `<select>`. The kit rules those (`.ui-btn` 14/600/sentence, `sm` 13,
   `.ui-input` 13/400) and §3.1's Label job list — "table headers, field labels,
   eyebrows, Kbd, status badges" — has no control on it.
2. **A big uppercase run is a heading, not a label.** Nothing on that job list is
   ever set at 16px+. The naive rule put R.A.B.B.I.T.'s client-estimate project
   title, an 18px `<h2>` a client reads, at 11px.
3. **`stone-400` is not metadata.** F1's ladder maps stone-300/400 to **ink-2**,
   the secondary BODY ink, and stone-500/600 to ink-3. Treating 400 as muted put
   four runs of D.O.G. help prose on the 12px Caption step — the C3b species of
   error, one step milder.
4. **`font-medium` is not a heading.** 500 sits on body copy as often as on
   structure; it classified D.O.G.'s red error banner as a heading.
5. **Tracking is not evidence of a label.** The first draft accepted
   `tracking-*` alongside `uppercase`. Of the 855 sites it caught, 853 carried
   `uppercase` anyway, and the one the tracking arm decided alone it decided
   wrong: `ProjectSummaryView`'s shot-naming preview sets the GENERATED NAME in
   `tracking-wide` next to a `Preview:` label. Capitals are a statement about
   what the text is; tracking is a nicety an author reaches for on anything
   small. **Pass 2's own guard found this.**

Distribution of the 2,582 sites: `text-dense` 1616, `text-label` 572,
`text-body` 159, `text-caption` 155, `text-h1` 42, `text-h3` 33, `text-h2` 5.

**The strongest evidence that the map is right**: not one file from Settings,

## 5. Traps hit

1. 🚨 **"Prove the server serves your worktree" is harder than it looks.** C3c's
   recipe (`curl …/src/ui/Table.jsx` must return a module, not `<!doctype
   html>`) proves a Vite dev server is answering — it does **not** prove WHICH
   checkout. Every worktree has `src/ui/Table.jsx`, and grepping the served CSS
   for a design-system string finds it in every checkout since F1. The only
   check that discriminates is a string **only your worktree has**: write a
   throwaway file into `src/`, fetch it, delete it. Took thirty seconds and
   would have caught a wrong-checkout session outright.
2. 🚨 **`/…\]\b/` DOES NOT MATCH `text-[12px]"`.** `]` and `"` are both non-word
   characters, so there is no word boundary between them. The arbitrary-size arm
   of the regex silently matched **nothing** and the first inventory reported
   706 sites instead of 2,582. It looked like a plausible number. Put the `\b`
   on the named arm only.
3. 🚨 **A class name is not always a class.** `dogHelpContent.jsx` carries
   D.O.G.'s help-page light theme as an embedded stylesheet whose selectors name
   the very classes the codemod rewrites (`.help-light h3.text-sm { … }`).
   Rewriting one does not restyle anything — it unhooks the override and the
   page silently loses its light theme. But **protecting it and walking away is
   just as broken**, because the selector then points at a class that no longer
   exists. Pass 1 protects the stylesheet AND re-points its three selectors, and
   the fixup is inside the pass so a clean-tree re-run reproduces it.
   `src/components/Home.jsx` has the same problem in comment form: it documents
   its own conversion by quoting the old class names.
4. 🚨 **An apostrophe in JSX prose desynchronises a naive string scanner.**
   Treating every `'` as a string opener makes the scanner skip to the next one,
   past real code and past any `//` in between. A quote that OPENS a string never
   directly follows a letter or a digit; one in prose almost always does.
5. 🚨 **`enclosingRun` walking back to "the nearest quote" is wrong inside a
   template literal**, where the nearest quote is often an interpolation's own.
   `${large ? 'text-[24px]' : 'text-[14px]'}` was read as two context-free
   one-token runs, and R.A.B.B.I.T.'s money figure lost the distinction the
   ternary exists for — a 24px total rendered the same size as a 14px line item.
   After fixing it, sweep for the shape: `? 'text-A' : 'text-A'` with identical
   arms. Four more exist and all four legitimately collapse 11.5px onto 12.5px.
6. 🚨 **F4's trap 4 again, and this time it ate MY guard.** `git checkout
   <sha> -- src` to re-run a pass from a clean tree also reverted
   `src/ui/typeScale.test.js`, because the guard lives in `src/` too. Twenty
   minutes of re-applying edits. **Commit the guard before re-running any pass**,
   or keep it outside `src/`.
7. 🚨 **F4's trap 3 again: node's `/tmp` on Windows is `C:\tmp`, Git Bash's is
   not.** `curl -o /tmp/x.json` then `node -e "readFileSync('/tmp/x.json')"`
   fails with ENOENT on a file curl definitely wrote. Use the session scratchpad
   path, spelled identically in both.
8. ⚠️ **A guard that reads the tree can break other tests without failing
   itself.** Six uncached sweeps over 271 files pushed four unrelated
   tree-walking tests (`devFixtures`, `authStateCallbacks`, `quizWiring`,
   `aiFiles`) past their 5s timeout under vitest's parallel workers, and tripled
   the suite's wall clock — while passing in 1.5s on its own. Every one of them
   passed in isolation, which is the confusing part. Cache the read.
9. ⚠️ **`\btext-label\b` matches inside `var(--text-label)`.** `-` is a non-word
   character, so the boundary is there. Four CSS-variable reads in
   `DevFixturesBadge.jsx` were reported as case-less labels. The lookbehind
   `(?<![-\w])` is load-bearing.
10. ⚠️ **A wide evidence window steals a sibling's content.** Reading a mono
    site's meaning from the JSX subtree is necessary (a money column is a
    wrapper with the figure in a child, so the direct text is empty) but the
    window can run past the element into the next one. Sampled and accepted: the
    default is DROP, so a stolen prose word errs toward the sans, which is the
    safe direction for this pass. Recorded because it is a real limitation.
11. ⚠️ **Timeline and Files both open on an EMPTY STATE.** Timeline with no
    project selected draws "No project selected. Open the Summary tab…"; Files
    draws "No project chosen". The first two screenshot runs captured those at
    both sizes and the PNGs looked plausible. Drive the page before shooting.
12. ⚠️ **App.jsx renders EVERY page at once** and hides the inactive ones to keep
    their state, so a Playwright locator resolves happily against a control on a
    page nobody is looking at. F4's trap 7 on a different surface. Dispatch
    clicks in-page instead.
13. 📌 **The brief says "eight scale steps"; the shipped `@theme` has SEVEN**
    (h1, h2, h3, body, dense, caption, label). Plan §3 says "Type steps: 7" and
    plan §5 says "the 8 steps" — the plan disagrees with itself and the CSS wins.
    There is no Display step; the transition title's 16.8px is inline and
    exempt (Q18).
