## 5. Traps hit

- **The pgTAP suites cannot share one transaction.** `tests.rls_setup()` runs as its caller and inserts into `auth.users`, and suite
  01 leaves the role `authenticated`; `tap-hosted.py` strips each suite's own `BEGIN`/`ROLLBACK`, so a second stacked suite aborts.
  One suite per call, as `tap-all.mjs` does. Round 1's chain rehearsal had them stacked.
- **`supabase functions download` overwrites `supabase/functions/<name>/` under its workdir**: scratch workdirs only
  (`--workdir`), and a copy deployed back from outside the repository has no `config.toml`, so it needs `--no-verify-jwt`.
- **`gateway-enrol` enrols without `WILSON_GATEWAY_KEY_SECRET` and says nothing** ("the first ticket makes the key"): the proof is a
  stored row in `gateway_signing_keys`, or a played clip that is not answered 503 `crypto_unavailable`.
- **Thirty idle minutes sign a session out** (`IDLE_SIGN_OUT_MS`), so a test plan's 4-hour clock cannot rest on an untouched
  session, and **a Forgot-password reset signs out every device** (`scope: 'global'`), so a check needing a second session runs
  before it.
- **Search her rulings before calling a gap unaccepted.** G6 and D14 are in `docs/design/GATEWAY_QUESTIONS.md`, cited in
  HARDENING.md and in the code's own comments; round 1 filed G6's gap HIGH and wrote that no ruling existed.
- **Quote a plan's gate verbatim.** The draft's paraphrase of §0 item 4 added "or she has ruled on each", then waived a finding on it.
- **A scoped gate's instance needs a comparator in the same areas**, or it is the class: TPN-SDLC-013's "the scans the app's CI
  has" did not exist.
- **A JS template literal eats `\b`, `\t`, `\n`, `\r`, `\f` and `\v` in Windows paths**: the doc scripts double every backslash
  and refuse to save a line holding a control character.
- **R2's new docs are LF in the working tree** (the Write tool), the older ones CRLF. The CRLF helper keeps each file's own endings,
  and git's "LF will be replaced by CRLF" warning on them is harmless: the blobs are LF either way.
- **P1 merged a 23rd function after the audit's snapshot**: every "22" in R2's documents had to move, and the gate does not cover
  `storage-read-urls` (SUMMARY says so; it signs GET URLs only, so TPN-NET-016's class does not reach it).
- **Walkthrough 85 was created on both sides** (add/add): one head, the sections in the head's order. M2 merged while this file's
  CI ran, so the brief's "once more" merge-in happened; its section then fell into place by itself.
- **The public API's 60 requests an hour are shared by every session on this machine**: R2's first CI read met a 403
  (`X-RateLimit-Remaining: 0`) and waited for the reset, reading once a minute after it.
- **The CI-only gateway flake** (`doorsOutside.test.mjs`'s "a play and a scrub make one viewing …") failed this branch's Vitest job
  too, on a tree that changes nothing under `gateway/`: read the job's annotations before calling a red run yours.
- **The reviewers' slips:** round 2's audit reviewer ran four read-only commands in the main checkout and left `/tmp/refs_dummy` (a
