## 5. Traps hit

1. 🚨 **A CANCELLED KEY IS NOT A KEY SOMEONE ELSE WANTED.** Round 1 made
   D.O.G. skip an Enter another listener had `preventDefault`ed. Bins'
   document listener, mounted on the hidden R.A.B.B.I.T. page with no page
   check, cancels every Enter not on a control once a file is selected, so
   D.O.G.'s shortcut died for the rest of the session. Gate on the PAGE.
2. 🚨 **LISTENER ORDER DECIDES WHAT A KEYDOWN-TIME CHECK SEES.** React 19
   flushes a SyncLane `setState` in the microtask checkpoint between two
   listeners, so a dialog an earlier listener closed has already
   unregistered by the time a later listener asks `overlayOpen()`. The
   session's activity listener (window capture, added in a passive effect
   after sign-in) closes "Still there?" on any key; the hotkey must run
   before it: `useLayoutEffect(() => install(...), [])`, state through a
   ref. A hotkey that re-installs on every pet change is always LAST.
3. **Every page stays mounted.** Any document or window key listener needs
   a page gate. D.O.G.'s Enter had none (fixed); Bins' keys, D.O.G.'s Alt,
   arrows and Ctrl+Z still have none (S2a-01, P1-04).
4. **Electron's Chromium 130 does not inherit `::selection`** (134+ does).
   Name the descendants (`x *::selection`). Playwright's Chromium inherits,
   so a probe cannot see the 130 behaviour; the CSS tests pin the selectors.
5. **Ctrl+= is +0.5 zoom level, ×1.095 a press.** On the 1024x700 floor:
   935, 853, 779, 711 CSS px wide after one to four presses. Round 1 called
   853 "one press"; it is two.
6. **`.wilson-dark-scroll *` is unlayered**, so it beats any layered
   `scrollbar-width: none`: a list that overflows draws its scrollbar and
   grows 8px (S2a-05, S2a-KR-3).
7. **`container-type: inline-size` is not a containing block for fixed
   children** in current Chromium (round 1's comment said it was). The
   container is still the tab list, not the nav.
8. **`sed -i` on a CRLF file rewrites it as LF** (it hit `dog.css` and
   `tokens.test.js`). Use the Edit tool, or a node rewrite that keeps the
   file's EOL.
9. **The Bash tool's shell strips backslashes inside double-quoted
   `node -e` strings**; put regexes in files.
10. **Node cannot import `src/layout/pages.js`** (it imports `./pageBars`
    without an extension), so the strip probe hardcodes the primary nav
    labels and says so beside them.
11. **In the dev fixtures a D.O.G. generation fails before the network**
    ("AIProxyError: Sign in to use AI features"), so a check that waits for
    an ai-proxy request is blind: watch for that error. And aborting
    `functions/v1` wholesale stops O.T.T.E.R. from loading.
12. **Vite answers any unknown path with `index.html` and a 200**: prove
    which checkout a port serves by a marker file's CONTENT.
13. **`git worktree remove` fails on Windows** with "Filename too long"
    inside `node_modules`; `fs.rmSync(path, { recursive: true, force: true })`
    handles long paths, then `git worktree prune`.
14. **The integration conflict was `src/ui/tokens.test.js`**: S1's
    signal-ink pairs and control beside S2a's signal-as-ink pairs and
    control. Keep both; each `it` block needs its own closing line.
15. `dog-state-shots.mjs` at 1440x900 timed out once at state 24 (the
    settings accordion) and passed on the re-run.
16. CI did not run on `po/**` until S3a's `rls.yml` change (in since the
    integration merge); a session's own pushes now start a run as well as
    the integration push. `gh` is not signed in here; the repo is public, so
