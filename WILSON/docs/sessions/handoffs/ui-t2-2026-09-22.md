## 5. Traps hit

1. 🚨 **THE CODEMOD'S GUARD HAD NEVER RUN ON WINDOWS, AND THE SUITE SAID SO
   QUIETLY.** A fresh worktree reports 139 files / 2823 tests with
   `src/ui/typeScale.test.js` failing to COLLECT on `SyntaxError: Invalid or
   unexpected token` — no file, no line, no stack. Measured with a probe pair:
   the same four-line module written once with CRLF and once with LF, each a
   `#!/usr/bin/env node` plus one `import`, both imported from one test →
   `{ "crlf": "SyntaxError…", "lf": "ok" }`. Vite's SSR transform hoists its
   shims above the module's first line and its hashbang strip does not account
   for `\r\n`. CI is Linux and LF, so CI could not see it. T3 found the same
   thing in the same hour; the repo-root `.gitattributes` on the branch is
   theirs. **After a fresh clone on Windows, delete and re-checkout
   `scripts/*.mjs` once, or the guard silently does not run.**
2. 🚨 **A SCANNER THAT ANCHORS INSIDE AN ATTRIBUTE, AND THE OPPOSITE MISTAKE.**
   T0's trap 17 is that a scan beginning at a class token is inside
   `className="…"` and inverts every quote after it. The inline equivalent
   would begin inside `style={{ … }}`, where the step-over T0 uses is WRONG in
   a new way: a style object often has no quote at all, so the backward walk
   finds an earlier attribute's. Anchor on `style=`, which is at attribute
   level — inside no quote and no brace.
3. 🚨 **TWELVE URLs IS NOT TWELVE SCREENS.** `/rabbit` with no project selected
   renders the project LIST — 33 text nodes — and every one of R.A.B.B.I.T.'s
   eleven tabs lives behind a project choice. The strongest evidence in the
   bundle was measuring a screen that held none of this lane's work. T0's trap
   16 caught this for the screenshots and nobody carried it across to the page
   check. `--tabs` fixes it; T1 found the identical shape on O.T.T.E.R.'s
   lesson surface.
4. 🚨 **THE FIXTURE IS NOT THE COMPONENT, AND THAT COST THREE PASSES.** "Salt
   Hours" has no file sizes (every `size` is null → `—`), no `pitch_bible` kind
   and an empty Intake file list. So "of the 230 cells, 32 overflowed and no
   other column did" was true of the fixture and false of the component: three
   more columns could not render their own content and nothing in the repo
   would have drawn them. A reviewer uploaded a real file through the drop zone
   and the Size cell reported `scrollWidth 71 > clientWidth 64` at once.
   **Drive the component with worst-case content, not with what the fixture
   happens to hold.**
5. 🚨 **AN INSTRUMENT ADDED TO CATCH A DEFECT THAT CANNOT SEE THE DEFECT.**
   `clipped` reused the size census's filter, which skips any element with no
   DIRECT text-node child — and a cell that wraps its text in a `<span>` has
   none, while the span itself is inline and reports `clientWidth` 0.
   Narrowing the Kind column to 18px made all 32 rows truncate and the number
   stayed at **0**. It walks its own list now and falls back to a `Range`.
   ⚠️ `clipped` is NOT a pass/fail number — a long file name is supposed to
   ellipsise. It is a number to compare between runs.
6. 🚨 **THREE LANES WROTE INTO ONE GUARD AND THE MERGES ARE THE HAZARD.** T1 and
   T3 had already collided there once — two consts named `INLINE_SIZE`, merged
   silently because they differed only in a body, and the file stopped parsing
   with `Identifier 'INLINE_SIZE' has already been declared` and no conflict
   marker. T2 arrived with a third. **Take the conflicted file WHOLE from
   whichever side is further along, then find what you are missing by running
   your own mutants against it** — not by reading both files and guessing. Five
   of this lane's eighteen stayed green against upstream's version and named
   exactly what to graft back.
7. 🚨 **A RATCHET SET FROM A DIFFERENT MEASUREMENT THAN THE ASSERTION MAKES.**
   Four app-wide ratchets were set from `node scripts/ui-audit.mjs`, which
   greps raw source, while the assertion used `sweep`, which skips comments.
   Two of the six `fontFamily` hits are inside comments, so the ratchet carried
   two units of slack and a mutant planting a real one left the suite green.
8. 🚨 **A CONTROL THAT RE-TYPES ITS SUBJECT PROVES NOTHING — THE SECOND
   SPECIES.** T0's version was a control re-typing its assertion's regex. This
   one was a control re-typing a predicate that lives in another file: the
   family fix could be reverted whole and all 2,910 tests stayed green. Export
   the predicate and call it.
9. 🚨 **`git checkout -- <file>` INSIDE A MUTANT LOOP DESTROYS UNCOMMITTED WORK
   IN THAT FILE.** A round-two fix to `ProjectFilesTable.jsx` was reverted
   mid-experiment and had to be rewritten from the transcript. T0's trap 8 is
   the same lesson from the other side. **Commit before you mutate.**
10. ⚠️ **SIZE A COLUMN AFTER YOU SETTLE ITS FAMILY, NOT BEFORE.** The Kind
    column was widened 90 → 104 for the mono and then moved to the sans in the
    same commit, where the same string is 61.8px rather than 85.8. The wrong
    number pushed the whole table 14px past the narrowest of its four wrappers.
11. ⚠️ **A COMMENT MOVES THE §7 AUDIT.** Quoting three retired class names
    verbatim pushed `font-bold` 2 → 3, `tracking-*` 13 → 15 and `uppercase`
    575 → 578, because the table greps raw source. T1/T3's `in code` column now
    separates the two, but prose still counts in the raw one.
12. 📌 **`classifyMono` ANSWERS PER ELEMENT, SO A HAND AGGREGATE OVER COLUMNS IS
    NOT THE MAP'S ANSWER.** "A row is mostly figures, four columns to two" is
    not a quantity the rule computes — `proseHits` is 0 or 1 within one body.
    Asked per column, it returned DROP for two of the nine, and both were
    shipping prose in the mono.
13. 📌 **A MAP THAT READS CLASSES IS BLIND TO A SURFACE THAT WRITES STYLES.**
    T0 found this once (`META_INK`). It is true of `uppercase` and of the
    heading weight too: without translating the inline spelling into the class
    one, all nine of `IntakePrepare`'s inline uppercase sites classify as lower
    case and one screen's six eyebrows land on two different steps.
