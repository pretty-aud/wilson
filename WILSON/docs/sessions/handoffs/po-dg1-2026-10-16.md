## 5. Traps hit

- **The model picker.** The session opened on Fable 5.1 against an Opus 5.5 brief; it stated
  the model on line one and stopped, and Audrey switched it. A session cannot switch its own
  model (`set_session_model` refuses "this session").
- **Escapes, three ways.** Bash heredocs halve `\\` (a `\\n` arrived as a newline inside a JS
  string); the Write tool decodes `\u` + four hex digits (a `’` in a pattern became `’`
  and stopped matching); Python in text mode writes CRLF on Windows, so a later
  `newline=''` script's `\n` patterns missed. What worked: edit scripts written with the
  Write tool, a helper that normalises line endings on read and restores them on write, and
  an assertion on every replacement's count. One replacement in `polarityRoundTrip.test.js`
  without that assertion silently did not apply; code review round 1 found it.
- **The browser pane's `screenshot` right after a click** can blend two frames (a dialog looked
  see-through); `zoom` or a Playwright shot shows the truth.
- **An open tab keeps old console errors** across navigations (a hook-order error from a
  hot reload mid-edit); read errors in a fresh tab.
- **`dateField.test.js` cannot see nesting:** any context selector whose ancestor class the
  file writes is assumed to reach its date fields (`.dog-refs-search .ui-input`). Give such
  inputs their own class.
- **The test data refuses every file download** (`devWriteRefused`), so a deck from chosen
  files cannot be generated there; and its notes need the `supabase` adapter mode, which the
  fixtures report.
- **D.O.G.'s source pins live in other tools' tests too:** `polarityRoundTrip.test.js` lifted
  the legacy reader out of the component; `rabbitFilesRender.test.jsx` pinned the size
  readers; both moved to the model.
- **A PDF's page count** cannot come from its bytes, nor from counting `/Type /Page` objects
  (stale revisions, compressed object streams), nor from any `/Count` (the bookmarks have
  one): the page tree's root `/Count`, found in the clear and inside the inflated object
  streams, and the linearization hint.
