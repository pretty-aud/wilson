## 5. Traps hit

- **The dev fixtures' vocabulary check reads lists from source.** `src/dev/fixtures/dataset.test.js`
  finds `SCENE_STATUSES`, `ASSET_STATUSES` and the rest by a regular expression over the views'
  files. Step 1 moved the asset statuses into `assetsTableView.js` and its run covered only the
  R.A.B.B.I.T. folder, so `dcc898b8` failed CI's Vitest job on exactly that file (the API's
  annotations name it). Step 2 points the check at the descriptions and lets it read a frozen
  list. **Run the whole suite, never a folder, before every push.**
- **A new cloud adapter method needs its fixtures twin** (`rabbitFixturesAdapter.contract.test.js`
  enumerates the cloud adapter's methods).
- **Each table's view carries its own layout.** On Scenes and Shots the content tab switches views,
  so it can switch Table and Gallery too (step 0 finding 2). Eleven older Scenes tests had clicked
  Gallery once and expected it on both.
- **The fixtures' adapter loads assets in `sort_order`.** A test that wants to see an order the
  provider's list does not have must change `sort_order` after the load (`ctx.updateAsset` /
  `updateLevel` patch in place, keeping the list's order).
- **`?fixtures=game`** turns on Levels and Experiences in the dev fixtures; in tests,
  `buildDevFixtures({ variant: 'game' })`.
- **A greyed control is `inert`** (GatedAction): Testing Library's role queries need
  `{ hidden: true }` to find it, and a screen reader never hears its reason (round 2, R2-5: the
  table's live region says it).
- **Two tabs are named Scenes** on that page (the page's and the content tab): scope a Playwright
  locator (`getByLabel('Content')`).
- **Playwright's drag of a table row from its centre grabs a field** and drops nothing; start it
  where no field is (the row's right end). The app's drop works.
- **`tasksViews.test.jsx`'s "until the map answers" test timed out once** under the whole suite's
  load (the loading line already gone), passed alone and in the next two whole runs. A timing
  test, not VW1e's; watch it.
- **The Bash tool halves a doubled backslash** in a command, and **a heredoc with certain quote
  mixes failed to parse** ("unexpected EOF while looking for matching"). Write such files with the
  file tools, or a patch file applied by a small script that keeps CRLF and refuses a block not
  found exactly once.
- **Git Bash rewrites an argument that starts with `/`** into a Windows path: `MSYS_NO_PATHCONV=1`.
- **This shell's `cat`, `sed` and `grep` hide `\r`.** The working files are CRLF; files the file
  tools write are LF; git normalizes both.
- **`npx supabase` has no Windows binary here**; the scoop CLI (`supabase`, 2.90.0) is the one that
  runs `db query --linked`.
- **pgTAP: a data-modifying CTE must be at the top level** (`WITH u AS (UPDATE …) SELECT is(…)`),
  and `scripts/tap-hosted.py` runs one suite per call.
