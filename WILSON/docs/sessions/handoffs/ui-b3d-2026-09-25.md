## 5. Traps hit

1. 🚨 **A BRIEF'S ATTRIBUTION IS A CLAIM: WALK THE SCREEN ALONE.** The 96
   failures "from the Settings panel left open under Help" were the
   Summary's files table: the walk's one browser context remembers the
   project. `--only <screen>` alone is the control.
2. 🚨 **MEASURE THE PAINTED GROUND, NOT THE CONTAINER'S.** The editor
   title's ground is its header band `#44403c`; B3c's figure used the body.
   Walk up the ancestors to the first opaque background in the running app.
3. 🚨 **THE KIT FIELDS CARRY BEHAVIOUR.** `Input` and `TextArea` revert and
   blur on Escape and blur on Enter; App.jsx's window Enter then toggles the
   companion, and a draft held in a panel's state is gone. In such a panel
   use a native field in `ui-input`, and answer Escape with
   `preventDefault()` (the kit Drawer skips an Escape a layer marked).
4. ⚠️ **`.ui-input` IS WIDTH 100%**: in a flex row give a field `w-auto
   flex-none` or `flex-1 min-w-0`. **The kit `Card` is a column**: a Button
   in it stretches, and its hit area with it: `self-start`.
5. ⚠️ **CLIPS CUT RINGS**: an `overflow: hidden` parent cuts the ring of
   anything flush with it (inset it, `outline-offset: -2px`), and a
   scroller stops Tab flush with its edge (`scroll-py-1`).
6. 🚨 **A FILE YOU WROTE IS A FILE YOU READ.** B3c's trap 1 holds for the
   Write tool too: a shell append to a file made with Write re-sent it whole.
7. ⚠️ **HEREDOCS LOSE A LEVEL OF BACKSLASHES** through the Bash tool (`\\` →
   `\`): a multi-line JS replacement stopped matching and an escaped
   apostrophe broke a test file. Write the script with the Write tool (B3's
   trap), or replace a whole block from a file.
8. 📌 `lastCompound` (`rabbitCssGuards.js`) splits inside `:is()`: a lane
   rule written `:is(.ui-card-title, …)` hides the kit class from
   `kitFights`. Write the selectors out.
9. 📌 The Browser pane pauses animations while hidden: right after opening a
   drawer, a measurement reads the entry animation's first frame (x = the
   window's width). Its `computer` coordinates are in the screenshot's frame
   (800x500 for a 1440x900 emulation), not CSS px.
10. 📌 Git Bash's `/tmp` is not Node's: pass `$(cygpath -w /tmp/x)`. The CI
    read itself had succeeded; only the parse failed, so no read was lost.
11. 📌 Hand arithmetic of contrast was wrong once (4.45 for a measured 4.54,
    from a mistyped channel): compute with a script.
