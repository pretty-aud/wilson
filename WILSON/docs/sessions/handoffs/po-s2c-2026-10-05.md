## 5. Traps hit

1. 🚨 **S2b-03 WAS RECORDED BACKWARDS.** "[outline]" is never clipped: it
   is ordered first in the breadcrumb's wrapping row, so it always keeps
   the line; it is the SUBJECT (with the course) that wraps to the hidden
   second line. Read a defect claim as a hypothesis; the sweep found it.
2. 🚨 **A CAP THAT SUBTRACTS A MEASURED TEXT WIDTH LEAVES A CLIFF.** The
   reviewer's `3.84em` was the note's own width to 0.05px; a note 0.09px
   wider (a font build, a renderer rounding glyph advances) lost the
   subject again. Leave slack (4em) AND fix the box to the same 4em
   (`flex: 0 0 4em; min-width: 0`): then no font can push the subject out.
   `--inject-css` in otter-reading-shots.mjs is how it was measured.
3. 🚨 **A MERGE THAT KEYS LIKE A PAGE MUST ALSO JOIN LIKE THE PAGE.** S2b's
   functions merge joins a nameless stored category as "General" because
   the Functions view heads it so. The Hotkeys page draws only `shortcuts`
   lists headed by `category`; copying the functions merge's STORED
   reading put new shortcuts under a blank heading or off the page (round
   1). Lift the page's own filter into the test.
4. **A parity test is only as wide as its generator.** A copy preferring
   `hotkeys` (round 1) and one collapsing inner spaces in the shortcut key
   (round 2) passed 600 seeds: no seed had both lists or an inner-space
   variant. Give the seeds every shape the code branches on, and pin the
   lines that must stay one.
5. **typeScale's cascade judge reads `:has()` (and every state or
   structural pseudo-class) as reaching every element** — a `:has()` rule
   on `.otter-crumb-current` "reaches" the lesson page's crumb too and
   breaks its pinned map. Scope by an ANCESTOR the judge models instead.
6. **The working tree is CRLF (`core.autocrlf=true`), CI is LF.** A test
   that slices source text on `'\n}\n'` passes on CI and fails here (or the
   reverse): normalise `\r\n` first. The plant script normalises its
   from/to texts to the target's line endings.
7. **The pet's index build is all-or-nothing**: ONE throw in `flattenDoc`
   for one course rejects the whole build and `retrieveOtterKnowledge`
   answers "could not be reached" for every course. Anything that reads a
   stored document there must skip what it does not understand.
