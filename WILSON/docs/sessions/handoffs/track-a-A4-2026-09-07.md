## 5. Traps hit (things the brief did not say)

- 🚨 **A COMMENT IS NOT A MECHANISM, AND I SHIPPED ONE.** `088dba8`'s
  mode-change effect cleared the open course and said *"the effect below re-lists
  on this change"*. **There is no such effect** — every `loadSoftwareList()` call
  in `Otter.jsx` is inside a handler or the mount effect, and nothing is keyed on
  `activeSoftwareSlug`. So the switch left the OTHER library's courses on screen
  and the headline feature looked broken. Found by checking my own comment, not
  by a test. Fixed in `214b2eb`. **Grep for the effect your comment promises.**
- 🚨 **A SLICE WHOSE BOUNDS ARE NOT CHECKED IS NOT A SLICE.** The wiring test
  built its slice from a nested `indexOf` of the effect's DEPENDENCY ARRAY text.
  Adding one dependency made that return -1, `.slice(0, -1 + 40)` collapsed to 39
  characters, and the assertions silently stopped checking anything. Assert both
  bounds were found and that the slice is longer than some floor.
- 🚨 **THE BACKSLASH TRAP BIT AGAIN, FOURTH SESSION, THROUGH THE HEREDOC LAYER.**
  A `\b` written into a regex through a quoted bash heredoc reached the file as
  an invisible **0x08 byte** — the code looked right in `git diff` and in the
  Read tool. The rule the previous hand-off wrote is correct and I broke it
  anyway: **never write a backslash into generated code; use `chr(92)`.** After
  fixing it I scanned every file this session touched for control characters and
  mixed line endings, which found a second problem: **0069 itself had MIXED line
  endings** (125 CRLF, 274 LF) because I assembled it from a CRLF source and LF
  fragments. Both fixed. That scan is worth running at every close-out.
- 🚨 **`open(path, 'w')` TRUNCATES BEFORE IT WRITES.** An encode error partway
  through (lone surrogates from `\ud83d\udea8` escapes) left `OUTSTANDING.md` at
  **0 bytes**. The committed copy made it a non-event. **Build the whole string,
  write it to a temp file, and `shutil.move` it into place** — and use `chr()`
  for astral characters, never surrogate pairs.
- 🚨 **A `db query` RUN CONCURRENTLY WITH `tap-all` RACES THE CLI's TEMP LOGIN
  ROLE.** The protocol says one `tap-all` at a time; it is actually one CLI user
  at a time. Suite 46 reported `QUERY FAILED … password authentication failed for
  user "cli_login_postgres"` and simply never ran — not a red assertion, not
  counted, and the planned total silently dropped by 10. Compare `planned`
  against what you expect, every time.
- 🚨 **THE MERGERS DO NOT TAKE A STORED DOCUMENT.** `mergeHotkeys`/`mergeFunctions`/
  `mergeNodes` were written for the GENERATOR's output (`doc.merge` feeds them
  `body.categories`). The stored shape differs for `nodes` (`{systems:[…]}`) and
  the stored hotkeys shape is `{category, shortcuts}` while `name`/`hotkeys` are
  only INCOMING aliases. Passing a stored document straight in merges nothing and
  reports success.
- **An anchor that matches four times should ABORT, not guess.** One breaker
  aborted because `setActiveSoftwareSlug(null);` appears four times in
  `Otter.jsx`. That is the runner working.
