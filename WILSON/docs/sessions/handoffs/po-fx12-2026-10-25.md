## 5. Traps hit

- **The smoke users' password is a GitHub secret**, so no session can sign in to wilson-dev by
  hand. The only signed-in calls are a CI step (`scripts/probes/ai-files.sh`, every push, her
  answer), as GW1's `gateway-ticket` probe does. Write a probe, push, read its annotations through
  `/check-runs/<job id>/annotations`: public and readable without signing in.
- **wilson-dev has no platform operator** (0 rows in `platform_operators`), so nothing operator-only
  can be exercised there. The whole store's counts wait for the operator console on staging or live.
- **app_events keeps rows 90 days**, and they are the only record of whose a stored file is. A
  file older than its row is nobody's to WILSON (FX12-01's date).
- **0021 lets any member insert app_events rows** with any context, including WIL-6001 with a
  forged `file_id`, but not the `admin` stream. Any attribution or certificate built on
  app_events must say which stream it trusts. A forged row must carry the member's own
  `workspace_id`, or the policy refuses it (403).
- **The Files API is generally available.** The beta header is optional and switches the response
  shapes (with it: `has_more`/`after_id`, no `expires_at`, no `ids[]`). `expires_in_seconds` is
  honoured even under the beta header. The new routes send no beta header; the upload keeps it.
- **The store refuses a lookup naming an id it cannot parse** (4xx for the whole batch).
- **Electron quits the moment its last window closes**, and an in-flight keepalive request dies
  with it when its CORS preflight needs a round trip. Loopback hides this (the preflight is
  instant): simulate a slow preflight before believing a keepalive.
- **The Admin Terminal's CSS guard treats every `data-` attribute as state** (a static spacing rule
  must be a class), and `typeScale.test.js` counts hand-set leading (`leading-relaxed` copied from
  a neighbour fails it). `devFixtures.test.js` lists every production file that may consult the
  fixtures; a new one is added there with its reason.
- **Type-checking a Deno function with `tsc`:** the installed supabase-js types every untyped table
  as `never`, in the existing functions too; filter those errors and read the rest (the scratch
  config maps `esm.sh` to `node_modules` and declares `Deno`).
- **`npm install --ignore-scripts` leaves no Electron binary**; the main checkout's
  `node_modules/electron/dist/electron.exe` (same version) runs a harness read-only.
- **No `python`** on this machine; edits by script go through `node`, and anything with
  backslashes through a file written with the Write tool.
- **A test that mounts the real provider can lose a race once the run is heavier.** VW1m's drop
  test reached for its target before the grouped rows were drawn; it passed on the base commit and
  failed on this branch only because four test files joined the run. Before calling a red test
  "not mine", run the base the same way (a detached worktree with a `node_modules` junction).
