## 5. Traps hit

- **JavaScript's `String.replace` reads `$'` in the replacement as "the text after the match".**
  An edit script inserting bash's `$'\n'` duplicated the rest of the file in memory (the exact-match
  guard refused it: "found 3 times"). Pass a function: `t.replace(from, () => to)`.
- **Moving a component breaks pins that read the source by its code, not its name.** A search for
  `PageSurface` found one pin; the full suite found the second, which read
  `display: currentPage === id ? 'flex' : 'none'` out of `App.jsx`. Search for the code line too.
- **The gap after a commit is not about its length** (review rounds 1 and 2): React asks the
  Scheduler for a paint in every commit (`requestPaint`), and Scheduler 0.27 yields while a paint is
  asked for, so a non-sync commit's passive effects are always a later task. FX14's §5 said "after
  the long commit"; it carries a dated pointer now. `state/gapPremise.test.jsx` holds the cause.
- **On this machine the waits' own drain usually lets React's effects in first**, so a mount
  without the status wait passed even with its render forced into the gap. Running zero-delay
  timers as microtasks makes the drain win, as on a loaded runner: then the status wait is what
  decides (25 red without it, none with it).
- **react-dom takes `Scheduler.unstable_requestPaint` when it loads**: a test that stubs it must do
  so before anything imports react-dom (a `createRequire('scheduler')` patch, then dynamic imports);
  its first case checks the stub is the one react-dom calls.
- **This machine has no `jq`**, so the probe's whole runs skip here; CI's runner has it (the test
  fails on CI without it). A scratch stand-in for the few filters the probe reaches ran them
  locally once; it is not in the repository.
- **node's `spawn('bash')` on Windows does not find Git Bash** (it is not on Windows' PATH, and
  `bash` could be WSL's): the test looks for `Git\bin\bash.exe` under Program Files.
- **A POSIX PATH entry with a drive colon splits**: `C:/…` in `PATH="…:$PATH"` became `C` and
  `/Users/…`. Use `/c/…` (`cygpath -u`).
- **A test that looks elements up by role and name in a loop over a big drawer is slow**: 20
  sections × 20 lookups took 3.1 s alone and passed 5 s under load. Find each once.
- **The kit's ring on a page's main region is cut off where the page has no gutter**
  (R.A.B.B.I.T.: two `overflow: hidden` ancestors share the region's rect): FX15-03.
- **The pet's sex is random per fresh browser**: a pixel comparison of Settings differs on that
  line alone.
- **The integration branch moved during the session** (`bfea9fd6`, DG2's brief): DG2 reworks
