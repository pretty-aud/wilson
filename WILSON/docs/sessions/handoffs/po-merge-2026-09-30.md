1. **A weekly usage limit stopped the workflow mid-run** (after merge A and its first review); it resumed from the cache eight hours later. A workflow's journal is what makes that possible — keep `resumeFromRunId` handy.
2. **A reviewer that "changes nothing" left an untracked draft migration** in the worktree (`0082_private_project_definers.sql`); the fix round adopted it. Check `git status` for untracked files after any review agent.
3. **Track B's local branch was ahead of its remote** (docs only); merging the local tip carried three commits no remote had. Compare `git log origin/<b>..<b>` before merging any long-paused branch.
4. **A migration number reserved in a plan can be consumed by a merge's own fixes.** The plan said 0082 for the shot lists; the merge took 0082 and 0083. Re-list `supabase/migrations` on the branch you stand on before writing a header.
5. **The SECURITY DEFINER copy trap (twice).** A track that copies a policy predicate into a function body freezes it; a later migration on another branch that tightens the policy (0072's privacy arm) never reaches the copy. Reviewers should diff every SECURITY DEFINER body against the current policy it mirrors.
