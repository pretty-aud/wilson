## 5. Traps hit

1. 🚨 **A TIE WITH THE KIT IS A LOSS.** A page stylesheet imported by a
   component loads BEFORE `src/index.css`; both write into `components`; so a
   one-class page rule and a one-class kit rule setting the same property
   resolve to the KIT. It silently killed two A1 overrides (the header ink,
   the tab strip's no-wrap) and every test stayed green. Give any override of
   a kit property a second class (`.ui-tabs.dog-page-tabs`).
2. 🚨 **`:focus-within` MATCHES MOUSE FOCUS.** Chromium focuses a button the
   mouse clicks, so a reveal on `:focus-within` fired after an ordinary click
   and changed the view (C1). Use `:has(:focus-visible)`.
3. 🚨 **PLAYWRIGHT HEADLESS HIDES SCROLLBARS.** Chromium launches with
   `--hide-scrollbars`, so every width a probe measures is a layout no user
   sees (D.O.G.'s main column has a 10px one). `chromium.launch({
   ignoreDefaultArgs: ['--hide-scrollbars'] })`. `ui-walk.mjs` and
   `ui-page-check.mjs` still launch with hidden scrollbars — their overflow
   and fit columns share the blind spot (recorded for V2).
4. ⚠️ **`JUDGED_BORDERS` MATCHED BY SUBSTRING.** `'.dog-page-tab'` excused
   `.dog-page-tabs`; an entry excuses every descendant rule too. A1's entries
   use an opt-in exact match; the other entries still use `includes`.
5. 🚨 **THE KIT'S COMPONENT FILES ARE BLOCKED FOR A LANE SESSION.** The
   permission classifier refused an edit to `src/ui/Tabs.jsx` ("Modify Shared
   Resources"). Edits to `src/ui/index.test.js` and `typeScale.test.js` (lists
   the brief names) were allowed. So a lane cannot build its own kit request
   even in its own commit; it files it (§6) and wears the kit's class contract
   on its own markup meanwhile (the C3 precedent). **It is a per-session
   decision, not a rule:** B1 committed a kit change (`7044eeb`) the same
   day. Try the edit; if it is refused, record it and file the request.
6. ⚠️ **MOVING `.env.local` ASIDE RESTARTS VITE WITHOUT IT.** The no-env suite
   run makes the running dev server reload with no Supabase URL ("supabaseUrl
   is required"); moving the file back does not bring it back. Restart the
   server afterwards, before any browser check.
7. ⚠️ **A GUARD CAN EXCUSE A BORDER BY ACCIDENT.** The one-border guard had
   exempted the output frame's three 2px sides because a `border-` token sat
   inside the NEXT ternary (`ui-pass4-surface.mjs` reads that as an active-tab
   indicator). Removing ternaries surfaces what the guard was silently
   excusing.
8. ⚠️ **TAILWIND v4 EMITS A PALETTE VARIABLE ONLY WHILE A UTILITY USES IT.**
   `var(--color-stone-700)` in a page stylesheet goes blank the day the last
   `bg-stone-700` in the app is restyled away. Write the value, or use `@theme`.
9. ⚠️ **TWO LANES, ONE GUARD LIST.** B1 and A1 both appended to `CSS_FILES`,
   `JUDGED_BORDERS` and `AWAITING_A_CALLER` within the hour; git conflicted on
   all three. Keep both and fix the count — and run the suite (T1 trap 3).
10. 📌 **EXACT-STRING TRANSFORMS AND THIS FILE.** Some JSX lines carry trailing
    spaces (`<div `) that a script's strings do not; match `[ \t]*\n`. And a
    `String.replace` replacement string expands `$&` — patching code that
    contains `$&` mangles it; pass a function.
11. 📌 **`ui-walk.mjs` TEXT PROOFS ARE EXACT-CASE; PLAYWRIGHT `getByText` IS
    NOT.** A sentence-case change to a proof string reads as "DID NOT OPEN".
12. 📌 **D.O.G.'s history is React state** — a probe fills it by pasting a
    deck into Import/export history. The resolver's preview opens on a 500ms
    hover intent.
