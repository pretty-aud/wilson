## 4. How it was run

`node scripts/ui-audit.mjs` for §1. For §2, a scratch scanner (not
committed) reusing `blankJsComments` / `blankCssComments` / `themeRange`
from `scripts/ui-audit.mjs`, one case-insensitive regex per rule; each hit
read in context before it was called judged or a finding. The kit's
exports were enumerated from `export` statements in every non-test
`src/ui/*.js(x)` and each name grepped (case-insensitively, as a word) in
`src/`, `scripts/` and `electron/`, the defining file and `src/ui/index.js`
excluded.
