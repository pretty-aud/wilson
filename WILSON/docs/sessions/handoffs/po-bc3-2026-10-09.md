## 5. Traps hit

1. **The Edit tool's parameters are JSON: a `\uXXXX` escape above U+007F in a regex or string is DECODED into the character before it reaches the file** (a `\u2028` became a real line separator inside a regex literal → "Invalid regular expression: missing /", in three files; `\u0000`–`\u009f` stayed as escapes). Write such escapes from a script that builds them with `chr(92)`, or type the characters' meaning another way; scan with Python for `[\u2028\u2029\u200b-\u200f…]` after any Edit that mentions them.
2. **The plants runner edits source in place: never run another vitest, the dev server's hot reload or a screenshot while it runs**, and never edit a planted file meanwhile (a planted fault would be photographed or compiled into the pane).
3. **The desktop→cloud migration carried no scenes or shots** (S3a's note in `runMigration.js`), so a take could not land: BC3 carries both (ids kept, parents first). Shot lists, items, edits and folders are still not carried (OUTSTANDING).
4. **`bin_files.location_id` is NOT NULL (0091)**, so the brief's "migrated with its location left empty" cannot be done: a clip whose root nobody names stays on this computer, LISTED, and a later run brings it; the panel keeps the question after the run for that.
5. **A Settings panel's workspace came from a second session read** (`supabase.auth.getSession()`), which the dev fixtures' tester mode has none of: `usePermissions().workspaceId` is the one source (the session's claims; the fixtures' in a dev build) and the panel reads that now.
6. **The fixtures' data modules import without extensions** (`'../ids'`): Vite resolves them, Node alone does not. A Node script reads them through the dev server (`page.evaluate(() => import('/src/dev/fixtures/data/scenes.js'))`).
7. **The Settings page scrolls inside the page**: a screenshot after `scrollIntoViewIfNeeded()` on a section's top clips its bottom; scroll the group itself to `block: 'start'`.
8. **A test clip named `T1` is also the slate line's "T1" (take 1)**: `getByText`-style picks found the wrong tile. Name test clips `Clip 0`, `Clip 1`.
9. **The toolbar's "New bin" and the rail's "+" are both buttons named "New bin"** to the accessibility tree: pick the text button by its text content.
10. **The context menu's Escape clears the Bins selection too** (pre-existing): a script must select again before pressing A.
11. **Playwright's `Space`** is `page.keyboard.press('Space')`; jsdom's is `fireEvent.keyDown(el, { key: ' ', code: 'Space' })` — and the desktop's Space CONTROL needs `HTMLMediaElement.prototype.play` stubbed, or jsdom throws "Cannot read properties of undefined (reading 'catch')" as an unhandled error.
12. **The dev build's Supabase client is real** (`.env.local`): a dev rehearsal of a cloud write must stub `**/rest/v1/**` and `**/storage/v1/**` in the page, or it reaches wilson-dev as anon.
13. **The Bash tool halves the backslashes in a command**: a `sed` replacement written `\\p` reached the file as `p`. A byte-level edit with backslashes goes through a Python script that builds them from `chr(92)` (`scratchpad/fix_regex_backslashes.py`), or through the Edit / Write tools, which keep `\\` as written and decode only `\uXXXX` above U+007F (trap 1). Scan after either.
14. **A fault whose test cannot tell it from its neighbour is not a guard**: the panel's re-seed of a suggestion a teammate's location came to hold was indistinguishable from `confirmedAnswers(answers, existing)`, so it was removed rather than planted and "caught" by luck.
