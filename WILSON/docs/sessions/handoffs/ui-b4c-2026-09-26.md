## 5. Traps hit

1. 🚨 **THE BINS TAB OPENS IN ITS FRAME VIEW**, so `rabbit-bins` never
   measured BinFileTable. The walk gained `rabbit-bins-list` ("List view").
   A screen named for a surface is not proof it draws that surface.
2. 🚨 **AN EXPIRED LOGIN KILLS A BACKGROUND SUBAGENT SILENTLY, MID-EDIT.**
   Round one's first corrections subagent stopped on a 401 with half its
   files changed. Check `git status`, then resume it by `SendMessage` to
   its id (it keeps its context); do not spawn a fresh one over its edits.
3. ⚠️ **A WALK SCREEN WHOSE OVERLAY HAS NO `role="dialog"` MEASURES THE
   HOST.** `rabbit-asset-video` read "all 0" for B4b because it measured the
   asset popup under the player. Compare the `dlg` box with the host's.
4. ⚠️ **A DOM FINGERPRINT NEEDS ONE NORMALISATION BEYOND `useId`.** Proving
   the fold byte-identical, every screen differed in one line: the pet's
   random sex ("F / Unknown / egg" or "M …") in hidden settings markup.
   `scratchpad/b4c-dom-fp.mjs` normalises it; nothing else differed.
5. 🚨 **A LIST YOU MAKE SCROLL BECOMES A TAB STOP.** Chromium 130 makes an
   overflowing scroller with no control keyboard-focusable. The kit trap
   did not know, so fixing RelinkDialog's list broke its Tab order. Fixed
   in the kit (§3); a lane that hand-rolls a trap must do the same.
6. ⚠️ **STRICTMODE LEAVES A `mountedRef` FALSE** unless the effect sets it
   true: FileAuditDrawer showed "Loading…" forever in dev, and the walk had
   measured that for two sessions.
7. ⚠️ **THE KIT'S `.ui-td` IS `overflow: hidden`**, so a focus ring in a
   cell padded under 3px is cut. Inset it (`outline-offset: -2px`) and give
   a scroller `scroll-padding`.
8. 📌 **The kit Drawer is `role="complementary"`**: a walk proof
   `dialog: true` cannot prove one; prove it by its own `<aside>`.
9. 📌 **`rabbitFilesCss.test.js` needs every file over 3,000 characters**:
   a thin config cannot join `FILES`; it has its own "config only" test.
10. 📌 **Appending with the shell to a file you wrote with the Write tool
    makes the harness re-send it whole.** Keep running notes shell-only.
11. 📌 B4b's traps 1–9 and B4's 1–10 still hold (the walk's step that
    matches nothing, `node --check` for the walk, `rulesOf` returns
    `{ sel, body }`, FileManager's test harness, `?fixtures=game` as
    `query`, heredocs lose a backslash).
