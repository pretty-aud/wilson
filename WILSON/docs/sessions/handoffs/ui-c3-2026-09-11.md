## 5. Traps hit

1. **🚨 CRLF, and a Python rewrite that silently flattened four files to LF.**
   Every `.jsx` here is CRLF with `core.autocrlf=true`. Reading with Python's
   universal newlines and writing with `newline=''` writes LF, which git then
   reports as "LF will be replaced by CRLF" on every subsequent touch. Four
   files were converted before it was caught. **The working spelling is read
   with `io.open(p, encoding='utf-8')` and write with
   `io.open(p, 'w', encoding='utf-8', newline='\r\n')`.** Reading with
   `newline=''` instead makes every `\n`-written search string miss, which is
   the *other* half of the same trap and cost a failed run.

2. **A quoted bash heredoc still choked on the edit script**, because the
   replacement strings contain JS template literals with backticks and `${}`.
   `unexpected EOF while looking for matching '`. The recorded advice is
   right: write the script to the scratchpad with the Write tool and run it by
   path. Heredocs are fine for commit messages, not for code containing JSX.

3. **`grep` output went stale within one session.** A verification grep for
   surviving inline ternaries reported hits at line numbers that no longer
   existed, on content already replaced and confirmed replaced by `sed` on the
   same file seconds later. Re-running the same check through a Python script
   gave the truth. **Do not trust a single grep as proof that an edit landed;
   confirm with a second, differently-shaped read.**

4. **`git checkout -- <file>` silently does nothing for an untracked file**,
   and `|| true` swallows the error. A deliberate break introduced to prove
   the CSS guard bites was therefore *not* reverted by the checkout, and the
   file sat broken until the system diff surfaced it. Revert a break in an
   untracked file by editing it back, and re-read after reverting.

5. **The Admin Terminal is not reachable by URL.** `/wilson/admin-terminal`
   and `/admin-terminal` both redirect to `/`. The page is reached by clicking
   **Resources** and then **Admin terminal**; after that the URL *displays* as
   `/admin-terminal`. In the Browser pane the working recipe is JS:
   click the button whose text matches `/resources/i`, wait ~400ms, click the
   one matching `/admin terminal/i`. `scripts/screenshot.mjs --pages
   root,/admin-terminal` **does** land on the page, because it navigates
   before the app's redirect settles.

6. **`curl`-ing a CSS file from the Vite dev server dumps the whole file** as
   an escaped JS string inside the HMR wrapper. It is a good way to prove
   which checkout is being served and a very expensive way to read two lines.
   Pipe it through `head -2` — and `head -c 200`, because the wrapper puts the
   entire stylesheet on one line.

7. **GitHub was intermittently unreachable** — two `git push` attempts failed
   with `Failed to connect to github.com port 443 after ~21s`, both succeeding
   on retry. Plan §6.3 already says to retry on rejection; this is the same
   advice for a transport failure. It is also why no CI run URL is recorded.

8. **`npx eslint` cannot run in this repo** — ESLint 10 wants
   `eslint.config.*` and the repo has none. AT-03 asks for a lint gate on
   imported-but-unused tokens; that gate cannot be added as an eslint rule
   without first migrating the config, which is out of this lane's ownership.
   Recorded as a kit/tooling request in §6. The `adminTerminalCss.test.js`
   dead-rule check covers the CSS half of the same concern.
