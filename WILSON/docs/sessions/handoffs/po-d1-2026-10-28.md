## 5. Traps hit

- **The desktop is still a new origin at every launch** on purpose (the gate reasons from it); what survives now is the userData file, seeded by the preload before the page's first script. `clearData({ dataTypes: ['localStorage'], excludeOrigins: [origin] })` must stay not awaited and excluding the live origin: awaited it had no bound on the way to the first paint, and an unbounded clear finishing after the seed would empty the live store and then the file.
- **A sandboxed preload loads only `electron`, `events`, `timers`, `url`**: its half of the storage is inline, and the test runs `preload.cjs` whole in a `node:vm` with that `require`.
- **`WILSON_DEV_OFFLINE=1` cancels `file://` loads too** (`isLoopbackRequestUrl`): the navigated-page case ran without it, on the build's `.invalid` cloud.
- **The Bash tool halves doubled backslashes in a heredoc** (the brief's warning, met again): a JSON spec with `\\.` arrived as `\.` and did not parse; specs and scripts go through the Write tool.
- **A planted control can stay green for a reason unrelated to the plant**: two did (the sender check's case used two different windows; the cut-short `.tmp` had the same mtime as the file); both cases corrected and re-run until they bit.
- **`vite build` through a junctioned `node_modules` writes `node_modules/.vite`** into the worktree's install (747 entries), and the first Vitest run adds the last one (748).
- **The brief's main-chunk figure (4,909,609) is not reproducible here**: the tip builds to 4,909,641 from both LF and CRLF archives with the same chunk hash; the delta is measured against this session's own figure.
- **The Fable weekly limit refused the design round and accepted both build rounds** a few hours later.
