## 5. Traps hit

1. 🚨 **`track-b-auth` is held by stale worktrees.** `git checkout` refuses
   ("already checked out at …"); the classifier BLOCKED `git checkout
   --detach` in the other worktree; `git checkout --ignore-other-worktrees
   track-b-auth` in your own worktree works. The stale worktrees then show
   your commits as reverse-diffs — nobody must commit from them.
2. **`gh` is not authenticated on this machine.** `gh run list` fails with
   "gh auth login". The repo is public, so the unauthenticated API works:
   `curl https://api.github.com/repos/pretty-aud/wilson/actions/runs?branch=track-b-auth`.
3. **The staging permission wall did not apply this session.** `functions
   deploy --project-ref <staging>`, `supabase link --workdir <scratch>` to
   staging and a DDL `db query --workdir` against staging were all allowed.
   Per command, per session — try, record, never work around.
4. 🚨 **PostgREST treats `*` as `%` in `like`/`ilike` values.** postgrest-js
   appends the pattern unescaped; PostgREST's only rewrite is `*` → `%`. Any
   `.ilike()` / `.like()` over typed input needs `*` handled and, better, an
   equality re-check on the rows. Swept 2026-09-06: `src/` and
   `supabase/functions/` hold exactly ONE `.ilike()` / `.like()` /
   `.textSearch()` call — this one. Grep again before adding a search field.
5. **The planner pre-evaluates STABLE functions inside RLS policies** for its
   estimates, so `set_config('request.jwt.claims', '')` makes an anon probe
   fail with 22P02 (JSON parse) before the privilege check can refuse with
   42501. Use `'{"role":"anon"}'`.
6. **A pgTAP fixture may insert into `auth.sessions`** with just
   `(id, user_id, created_at, updated_at, ip, user_agent)` on hosted Supabase.
7. **Hosted `postgres` is BYPASSRLS, not superuser** — a SECURITY DEFINER
   function owned by it bypasses FORCE RLS (how the hooks insert; what 0030's
   trigger already relies on). `current_setting('role')` is `'none'` on
   GoTrue's own connection and `'authenticated'` under PostgREST — the stamp
   trigger keys on that.
8. **Recording a by-hand migration:** `supabase migration repair --status
   applied 0070 --linked [--workdir <dir>]`; the file must exist under that
   workdir's `supabase/migrations/` (copy it into the throwaway dir).
9. **A subagent is a good R2.** A fresh-context, read-only reviewer over the
   R1 commit found four real things the author had stopped seeing, at no
   cost to this session's context. Rule 5 of the tandem rules is about
   fan-outs that WRITE; a reader is fine.
10. Playwright's second `webServer` rebuilds the web target every run
    (~1–2 min) unless `:4174` is already serving.
11. One `git push` failed with "Failed to connect to github.com port 443"
    (transient); a retry loop handled it.
12. `supabase db query` returns `{"rows": [...]}` JSON; parse it with node
    (`JSON.parse`, not `require`).
