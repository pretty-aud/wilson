## 5. Traps hit

1. **`preview_start` runs launch configs from the canonical checkout, not
   the worktree.** The first `wilson-dev` server served
   `…\wilson\WILSON\src\index.css` (Audrey's `feat/demo-2026-09-11`
   checkout) while this worktree's edits went nowhere. Fix: a launch entry
   whose `runtimeArgs` pin npm to the worktree with `--prefix <worktree>/WILSON`
   and a separate port (`wilson-dev-f1`, 5213), in the worktree's untracked
   `.claude/launch.json`. Always confirm with
   `curl -s localhost:<port>/src/index.css | grep __vite__id`.
2. **Git Bash rewrites a bare `/` argument** into `C:/Program Files/Git/`.
   `scripts/screenshot.mjs` takes `--pages root` for that reason.
3. **`App.jsx` and most `.jsx` files are CRLF on disk.** A multi-line perl
   pattern with `\n` silently matches nothing; single-line patterns work.
   `git show HEAD:src/…` fails because the repo root is one level above
   `WILSON/`: use `git show HEAD:./src/…`.
4. **Tailwind v4:** `@theme static` is what makes every custom property
   reach the runtime even before a utility uses it (inline `var(--…)` sites
   need that). `--text-h2--font-weight` style sub-properties do apply
   through `text-h2`. Durations are not a namespace: `@utility
   duration-state { … }` provides them. `@layer components` for the kit's
   `.ui-*` rules so utilities still win.
5. **`document.fonts.check()` returns true when no face is declared** — it
   is not proof a font loaded; read `[...document.fonts]` statuses.
6. **The first cut of the sweep script counted only the bare `outline-none`**
   (2 sites), wrote only those two files and reported success. Count every
   spelling before and after; the committed script does.
7. **The review's 40-percent focus ring measures 1.7:1 on paper** — not a
   focus ring. The token is the full signal (4.9:1); the test pins both.
   Also: `#ea580c` IS a legible ink on paper (4.91:1) — the same pair as
   ink-light on signal — do not "fix" orange labels on dark.
8. **jsdom + Testing Library:** vitest's environment stays `node`; each
   render test opts in with `/** @vitest-environment jsdom */`. RTL's
   auto-cleanup needs `afterEach(cleanup)` explicitly (no globals).
   `forwardRef` components are objects, not functions (`typeof`).
   `element.blur()` in jsdom fires a real blur, so an Enter-commits test
   must not also fire a manual blur.
9. **`focus:outline-none` beats the global `:focus-visible` rule on
   specificity** — that is why the sweep exists; a new one is a defect.
10. **The classifier blocked a perl edit of `.github/workflows/rls.yml`.**
    Left as is (§2).
11. **`visual-language.md` is not in the repo** (it is a skill file), so
    the plan's "rewrite it in the same commit" cannot be a commit.
