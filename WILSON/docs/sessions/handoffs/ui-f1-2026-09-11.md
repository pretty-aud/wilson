## 5. Traps hit

1. **`preview_start` runs launch configs from the canonical checkout, not
   the worktree.** The first `wilson-dev` server served Audrey's
   `feat/demo-2026-09-11` checkout while this worktree's edits went nowhere.
   Fix: a launch entry whose `runtimeArgs` pin npm with
   `--prefix <worktree>/WILSON` and a separate port (`wilson-dev-f1`, 5213)
   in the worktree's untracked `.claude/launch.json`. Confirm with
   `curl -s localhost:<port>/src/index.css | grep __vite__id`.
2. **Git Bash rewrites a bare `/` argument** into `C:/Program Files/Git/`;
   `scripts/screenshot.mjs` takes `--pages root` for that reason.
3. **`App.jsx` and most `.jsx` files are CRLF on disk.** A multi-line perl
   pattern must use `\r?\n`. `git show HEAD:src/…` fails because the repo
   root is one level above `WILSON/`: use `git show HEAD:./src/…`.
4. **Tailwind v4:** `@theme static` emits every custom property, namespaced
   or not. `--text-h2--font-weight` applies through `text-h2`. Durations
   are not a namespace (`@utility duration-state`). The kit's `.ui-*` rules
   sit in `@layer components`; the global rules in `@layer base` — anything
   UNLAYERED in index.css beats every utility regardless of specificity
   (round 1 measured it on the built sheet). Keep new global rules layered.
5. **`document.fonts.check()` returns true with no face declared**; read
   `[...document.fonts]` statuses instead.
6. **The first cut of the sweep script counted only the bare `outline-none`**
   and reported success after writing two files. Count every spelling.
7. **The review's 40-percent focus ring is 1.7:1 on paper; the full signal
   is 4.91:1 on paper but 1.0:1 on the orange bars and 1.6:1 on the light
   ground** — a focus token needs a scope per surface class. `#ea580c` IS a
   legible ink on paper (4.91:1) — do not "fix" orange labels on dark.
8. **jsdom + Testing Library:** per-file `/** @vitest-environment jsdom */`;
   explicit `afterEach(cleanup)`; `forwardRef` components are objects;
   `element.blur()` fires a real blur in jsdom.
9. **A `<label>` wrapping a `<button>` forwards clicks on the text** — a new
   click target where the old span-based Toggle had none (C1). The kit's
   Switch uses a `<span>` + `aria-labelledby`.
10. **`role="menu"` promises arrow-key navigation**; do not add the role
    before the keyboard model exists.
11. **Rulings can land mid-session.** The controller pushed Audrey's §2
    answers (Geist, 3/6, Q17, Q18, Q10) after this session had built Inter,
    4/8, the Q17 flag and a Display step. Merge `origin/feat/ui-overhaul`
    and re-read §2 at every milestone, not only at the start.
12. **The seeded tester's password is a GitHub secret** (`DEV_PROBE_PASSWORD`),
    not in the repo. Audrey's own account is on staging, not wilson-dev,
    which is why her sign-in in the pane failed — hence the dev auto
    sign-in. Never type a password; never fetch the secret.
13. **The Browser pane's viewport emulation scales the app down** inside the
    pane and paints orange around it; Audrey read that as the light block
    not reaching the edges. Reset to `desktop` before showing her anything,
    and take real-viewport captures with `scripts/screenshot.mjs`.
14. **The classifier blocked a perl edit of `.github/workflows/rls.yml`.**
