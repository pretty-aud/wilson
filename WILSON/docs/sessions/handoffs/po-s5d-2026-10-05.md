## 5. Traps hit

1. **The app's untracked root `.claude/launch.json` blocked the checkout
   again** (S5b's trap 1): moved to the scratchpad, never deleted.
2. **A `<select>` with a `size` is a listbox, not a combobox**: the walk opens
   the dropdown for its picture by setting `size`, so it finds the select by
   class, not by role.
3. **Tailwind's preflight makes every svg a block**: the eye in the words sat
   on a line of its own until it was `inline-block` (now a flex piece).
4. **A shell heredoc appended LF lines to a CRLF test file**; normalised with
   node. Text with backslashes or apostrophes goes through the Write/Edit
   tools, as the brief says — and a `node -e` replace with a regex
   backslash in it fails to match the same way (use the Edit tool).
5. **The settings drawer opens locked**: the walk turns "Editable" on before
   it can reach "Show weekends".
6. **A whole-image compare cannot prove "moved only by the bar"** (the
   viewport-anchored minimap frame, the scrollbar, the pet, centred hovers):
   hide the bar instead and compare — identical but for S5p's trap-6 arrow.
7. **jsdom measures the minimap 0 wide, so it draws no bars**: tests that
   read minimap bars stub `clientWidth` for `.rb-tl-ov` (1400, S5p's).
8. **`bundleRef` catches up in an effect after a render** (S5b's trap 2, from
   the other side): a failed write must roll the REF back too, and only a
   network-paced test sees it — a microtask-paced one never renders between
   the drop and the failure (`IS_REACT_ACT_ENVIRONMENT = false` and real
   timeouts, as `bidVersionsReview.test.jsx` "S5d R1-01" and "R2-02" do).
9. **Only TASK_SCHEDULE fields make a version unsaved**: a title change does
   not. A test that needs "Unsaved changes" changes `bid_days`.
10. **Every edit under `WILSON/` reloads the dev server's open pages**
    (Tailwind 4 scans the .md files too: "page reload docs/OUTSTANDING.md"),
    and moving `.env.local` aside restarts the server twice. While a
    reviewer or a probe drives the server, edit nothing under `WILSON/`:
    drafts go in the scratchpad, and the walk takes `--out`.
11. **In a flex row a text piece's edge spaces are dropped**: "Open: " and
    " · " keep theirs only with `white-space: pre`. **lucide icons carry
    their own classes**: a test reading class names filters to its own.
12. **A fractional `flex-shrink` cannot rank flex items**: when the shrink
    factors of the items still free to shrink sum below 1, the browser hands
    out only that fraction of the overflow (MEASURED: words at
    `flex-shrink: 0.001` never shrank and the bar ran 307px past 1024). Rank
    by caps (the dropdown's `clamp()` cap) and whole factors instead.
13. **The scratch plant runner runs vitest through a shell**: a `-t` grep
    with `|` became a pipe (a non-zero exit from the pipe's second half read
    as CAUGHT), and one with spaces is split into file filters. A verdict
    with a failure count is real (the suite is green before each plant);
    one without needs a re-run with a single-word grep.
14. **The desktop app can stop the preview server on its own** ("was stopped
    by the app"): restart it with `preview_start` by name and prove the
    marker again before trusting a probe.
