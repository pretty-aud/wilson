## 5. Traps hit

- 🚨 **`typeScale.test.js` requires every file under `src/tools/` to belong to a type-scale lane** (T1 Dog and Otter, T2 Rabbit). A new tool folder belongs to none, so the Vitest job goes red. Her ruling: "MO1 or MO2 adds it (Recommended)". One regex line; not touched here.
- 🚨 **Measure at her real scale.** Scale 1 hides the cost of lines: a 1 px line is a hairline there, and nowhere else. The cloud (scale 1, software raster) and this session's first pass both missed it.
- 🚨 **Check size and scale at the row, not at launch.** The first pass's rows on the 4K display ran at 3440 wide and scale 1 although the launch's readout said 2560 and 1.5 (why was not found). The harness now fails such a row.
- 🚨 **A row must print what it drew.** The first pan rows read a healthy 16.9 ms while drawing 0 dots: the harness threw the camera off the graph.
- 🚨 **The blank frame loop cannot see a presentation problem:** it draws nothing, so nothing has to reach the screen; it read 16.7 ms beside rows at 80 ms. Add a loop that changes one pixel. Playwright also emulates `document.hasFocus()`: read the window's real place in the z-order.
- 🚨 **Run the repo's own binaries from `WILSON/`** (`./node_modules/.bin/vitest`, `./node_modules/.bin/vite`). A bare `npx vitest` from the repository root downloaded Vitest 5.0.5, ran the e2e specs and left caches in a stray root `node_modules`.
- 🚨 **Frame lateness is not frame cost.** At 60 Hz a healthy frame arrives up to 16.7 ms after it is asked for, so a governor that judges "headroom" on lateness never leaves light mode; the exit judges script work, the entry judges what the person saw.
- 🚨 **Do not feed the governor the frames of a settling layout**: the worker holds a core, frames come late, and light mode cannot fix that.
- Batching a stroke is worse than either extreme: 8 segments a stroke took 242–458 ms a frame at 4K. Only one segment a stroke, or a true hairline, takes the browser's fast path.
- Playwright's own Chromium will not start on her PC (`spawn UNKNOWN`; Windows refuses the unsigned `chrome.exe`). Use `channel: 'chrome'` with a scratch profile; do not touch a security setting.
- `--window-position` does not place a window on the second display when Playwright emulates the viewport: use `viewport: null` and CDP `Browser.setWindowBounds`.
- A fresh desktop worktree holds an untracked `.claude/launch.json` that blocks `git checkout` of any branch tracking that file: move it aside first (it is a subset of the tracked one).
- Git Bash mangles `git show rev:.path` without `MSYS_NO_PATHCONV=1`; a heredoc through this Bash tool loses a backslash pair (write scripts with the Write tool). Sources are CRLF in a Windows worktree: a script that patches them must normalise.
- A mutation lens has no natural size: 296 plants gave 18 of round 1's 52 reports and 36 minutes. Give the next one a number.
- The worker must not post every batch: posting at most every 32 ms took feedback while streaming from max 124 ms to 66 ms on the cloud box. `forceSimulation()` starts a d3-timer the moment it is made; `.stop()` at once (done). Module workers do not load from `file://`; serve the build over HTTP to measure.
