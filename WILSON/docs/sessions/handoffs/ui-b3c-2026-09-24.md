## 5. Traps hit

1. 🚨 **A FILE YOU HAVE READ, EDITED BY A SHELL COMMAND, COMES BACK WHOLE.**
   Editing `rabbitTimeline.css` or `Drawer.test.jsx` with `sed -i` or a
   `node -e` splice after reading it made the harness re-send the whole
   changed file (5–10 KB each) — the largest single cost in this session's
   300 KB. Use the Edit tool on anything already read; keep shell edits for
   files you have not read.
2. ⚠️ **CRLF IN THE WORKING TREE.** Every checked-out file is CRLF (Git for
   Windows' system `autocrlf`); a `node` splice must write the file's own
   newline; the Edit tool writes LF lines into it. Git normalises on commit
   (blobs are LF) and only warns.
3. ⚠️ **A PROBE THAT HOVERS BY COORDINATE HITS THE PET.** At 1024x700 the
   chart row's right end is under the pet's corner (C5): the row never saw
   the pointer. Pick the point with `elementFromPoint` (the rows probe does).
4. 🚨 **THE KIT DIALOG DOES NOT PORTAL.** Rendered inside a surface whose
   backdrop closes on click (TaskEditor), a click on the Dialog bubbles
   (React tree) to that handler and closes the surface under it. Render it
   as a sibling.
5. 📌 **A TASK BAR'S CLICK OPENS THE DETAIL POPUP, NOT `TaskEditor`.** To reach
   the editor's Delete in a probe, click a PHASE bar.
6. 📌 **`normal(jsCode(src))` KEEPS THE NEWLINES BETWEEN JSX ATTRIBUTES**: a
   guard's regex over a multi-line element needs `\s+`, not a space.
7. 📌 B3's traps still hold: scripts through the Write tool (backslashes);
   SMIL arrows need their animation elements removed before a pixel proof;
   a subagent's edits hot-reload the shared server; scanner line numbers are
   of comment-stripped code; `.claude/launch.json` is tracked (B3c's
   `b3c-worktree` entry, port 5259, was never staged).
