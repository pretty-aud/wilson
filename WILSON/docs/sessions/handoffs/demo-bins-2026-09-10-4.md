**The three defects the run found, fixed in `ff1b031`:**

- **After a relink every MP4 tile fell back to its icon** (measured: 415 on
  every MP4 thumbnail after "Relinked 13 files…", while the stills' posters
  came back). The poster cache is keyed by path + mtime, so the new path had
  no poster, and nothing re-probed a row whose `probe_status` was already
  `done`. Fix: `binRelinkApply` in the provider — where both the dialog's
  Apply and the auto-relink on open land — hands every relinked row that has
  columns or a poster to `probeBinFiles` in the background
  (`rowsToReprobeAfterRelink` in `bins/binMedia.js`; documents skipped); the
  header says "reading N" and the posters return. **vitest** (the helper and
  a source pin) and **app** (three relink rounds after the fix, POST
  thumbnail 200 for every MP4, every tile a real frame).
- **The re-probe then drew black posters for six clips in seven** on a
  colour-bar file (measured by loading each poster on a canvas: mean
  luminance 0). Chromium fires `seeked` before the frame is always ready for
  `drawImage` under load; the first probe of a session had shown one black
  in seven too. Fix in `bins/binProbeFallback.js`: wait for a presented
  frame after the seek (`requestVideoFrameCallback`, else
  `HAVE_CURRENT_DATA`, bounded), and when the drawn frame is uniformly black
  (`isBlankFrame`) draw again after a beat, then once more a second further
  in — a clip that fades in from black gets its first real frame, a clip
  black all through keeps its frame. **vitest** (`isBlankFrame`) and **app**
  (two relink rounds after the fix: 14 of 14 posters real, luminance 126).
- **`24A_2_T3PU_B.mp4` was suggested as take 2 with no modifier**: the take
  token regex required the token to end after the digits, so `T3PU` fell
  through and the bare shot number became the take. Fix in
  `parseNameSuggestions`: a modifier glued to the take token (`T3PU`,
  `TK04MOS`) and to a bare take after the slate (`24A-3PU`). **vitest** (five
  cases) and **app** (after a restart of the dev instance, the add dialog
  reads "24A · T3 PU · B cam").

## 5. Traps hit

- 🚨 **The pick routes open NATIVE dialogs from the main process, even with
  the window hidden.** Clicking the relink dialog's "Choose the folder they
  moved to…" in the harness put a real "Choose the folder the files moved to"
  dialog on Audrey's desktop (the `pickDirectory` stub in the harness is not
  what runs — `pickBinFolder` is a server route). Found and cancelled with
  `EnumWindows` + `PostMessage(hwnd, WM_CLOSE)` on the `#32770` window owned
  by the electron PID. Never click Add ▾ → Files… / Folder…, "Choose the
  folder" or the bin menu's Add files… / Add a folder… from the harness; use
  a synthetic drop to add, and for the relink dialog's scan path make the new
  folder a known root first (drop one file from it, add it as an instance),
  then click that root's **Scan**.
- 🚨 **Minimizing the dev Electron window is not enough** — Audrey found it
  in the taskbar and tried to sign in ("wtf i cant log on"). Hide it:
  `ShowWindowAsync(MainWindowHandle, 0)` (SW_HIDE) right after launch; the
  server keeps running; tell her in the first message that the window and
  any dialog it opens are yours.
- **The Browser pane's named keys `space`, `Return`, `Escape` arrive as an
  empty `key`** (a document keydown listener recorded `key: ""`); `Enter`,
  `Tab`, `F2`, `End`, `Delete`, `ctrl+z`, `ctrl+y` and letters arrive
  correctly. For Space / Escape dispatch a synthetic `KeyboardEvent` on the
  focused element. `ctrl+a` inside an input does not select-all (pane
  artefact; the app's guard stands down in fields) — use `input.select()`.
- **Editing a test file under `src/` makes Vite fully reload the harness
  page** (as does a provider edit): every `window.__helper` and the undo
  history is gone; land on Summary and re-open the project and the tab.
- **The working tree is CRLF** (`git ls-files --eol` → `i/lf w/crlf`), so a
  multi-line string replacement must normalise EOL before matching and write
  the file's own EOL back; single-line replacements match regardless. A bash
  heredoc (`<<'EOF'`) still ate the backslashes of a JS regex in the script:
  write patch scripts with the Write tool and run them with `node`.
- **A shot status change is a new history action and clears the redo
  stack** — after undoing a takes assignment, changing a status makes Ctrl+Y
  a no-op. Normal undo semantics; it cost a re-run of step 17.
- **`window.confirm` is the six-plus removal confirm**; the pane suppresses
  native confirms, so override `window.confirm` in the page to record the
  message and return false.
- **Right-clicking a tree row selects that bin** (the grid changes under a
  test that then looks for a tile); click the bin you want after the menu.
- **The relink dialog's `[role="dialog"]` and the takes dialogs are
  `role="dialog"`; the shot popup and the context menus are not** — find
  them by text or title.
- **Fetching a poster on a canvas and averaging its pixels** is the honest
  check that a poster is a frame and not black; the tile looks fine in a
  scaled screenshot.
