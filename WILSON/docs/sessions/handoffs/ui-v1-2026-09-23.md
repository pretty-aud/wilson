## 5. Traps hit

1. 🚨 **TAILWIND v4 COMPUTES ITS PALETTE AS `oklch()`, AND AN `rgb()` PARSER
   SEES NONE OF IT.** `bg-stone-800` computes to
   `oklch(0.268 0.007 34.298)`, `bg-black/50` to `oklab(0 0 0 / 0.5)`; only
   `@theme`'s hex tokens and inline styles come back as `rgb()`. V1's first
   census parsed `rgb()` alone, so every palette colour was skipped in
   silence — the settings slide-outs read as TRANSPARENT and the contrast
   list held only inline hex. Read colours through a 1x1 canvas
   (`fillStyle` → `getImageData`); control it with a known pair
   (`oklch(0.268 0.007 34.298)` → `41,37,36`, i.e. `#292524`). Reset
   `fillStyle` first: it IGNORES a value it cannot parse.
2. 🚨 **TWELVE URLs, THEN SEVENTY-FIVE SCREENS, AND A PROOF ON EVERY ONE.**
   T0, T1 and T2 each found a check measuring the wrong screen. V1 found the
   fourth: `ui-page-check --tabs` printed "NOT OPENED" only when the button
   was MISSING, so a click that landed while the previous tab was still
   settling measured the previous tab under the new name — one run's Intake
   row carried Summary's census digit for digit. A tab's label is on screen
   whichever tab is showing; only its SELECTION state can prove it. The
   walker's gate caught the same thing again on its own run.
3. 🚨 **A CENSUS ROW THAT MATCHES ONE SPELLING IS BLIND TO THE OTHERS.**
   `border-2` read 0 while D.O.G.'s output panel drew its frame as
   `border-t-2 border-l-2 border-r-2 border-b-2` — 37 per-side 2px utilities
   in 4 files. The audit has a row for them now.
4. 🚨 **THE DECLARED FAMILY IS NOT THE DRAWN ONE.** Every element declares
   Geist whether or not Geist drew a glyph; fontsource's Latin subset has no
   `→`, so "Run Intake →" draws its arrow in Segoe UI Semibold under a
   declaration that says Geist. `CSS.getPlatformFontsForNode` reports the
   font's INTERNAL name (never the `@font-face` alias), and an EMPTY list
   means "not laid out yet", not "no font" — V1's first glyph probe gave a
   different answer on each run until it waited two frames and
   `document.fonts.ready`. A character scan misses `&rarr;` too.
5. ⚠️ **`grep $'\r'` IN GIT BASH IS NOT A CRLF DETECTOR.** It listed all 22
   `.mjs` files as CRLF when none were, and found nothing in a control file
   that was. Count bytes: `tr -cd '\r' < f | wc -c`.
6. ⚠️ **PYTHON ON WINDOWS WRITES CRLF BY DEFAULT.** `io.open(p, 'w')`
   translates `\n` to `\r\n`; three `.mjs` scripts came out CRLF, which is
   T3's trap 1 by a new road. Pass `newline=''`, and count bytes after.
7. ⚠️ **HEREDOCS AND `node -e` EAT BACKSLASHES HERE** — four times, each in a
   regex. Use the Write/Edit tools for code. T1 trap 17 again.
8. ⚠️ **TWO VITE SERVERS ON ONE ROOT SHARE `node_modules/.vite`.** Starting
   the second while the first was being measured forced a reload on the
   first: `/settings` measured 0 text nodes. Start both before measuring.
   Separately, Vite reloads a page when it first meets a dependency it has
   not pre-bundled (a lazily loaded Budget view): the walk now retries a
   screen once on "Execution context was destroyed".
9. ⚠️ **HAND-ROLLED OVERLAYS PUT THE PANEL BESIDE THE BACKDROP, NOT IN IT**,
   and the dev-fixtures badge (z200, 249x24) is a fixed opaque layer too —
   six overlays were first "measured" as the badge. `openDialog` excludes it
   by test id and requires a candidate to intersect the viewport.
10. ⚠️ **`hOverflow` IS DOCUMENT-LEVEL.** Rate Card's table overflows inside
    a scroll container and every page check read `false`. Look at it.
11. ⚠️ **A WRAPPED CELL IS NOT A CLIPPED ONE.** Tasks' dates break mid-token
    at 1280 and `clipped` read 0. `stopPointCensus.broken` measures it.
12. 📌 **A CENSUS IS NOT A GATE.** ~640 contrast failures, 37 C6, 254 unnamed
    controls — at stop point 1 most are lanes A/B/C's planned work. The walk
    FAILS only on face, weight, case, tracking, dialog fit, errors, unnamed
    controls and a screen that did not open, each against a `KNOWN` list
    keyed on screen AND element; the rest it counts.
13. 📌 **DevTools round trips are the walk's whole cost.** Sequential, a dense
    table took 30-50s; pipelined in chunks of 50, ~13s.
