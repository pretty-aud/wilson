## 5. Traps hit

1. 🚨 **A PROOF THE PAGE UNDERNEATH ALREADY SATISFIES IS NO PROOF.** Round
   one of the review found four: "R.A.B.B.I.T." (the shell's nav, on every
   page), "Salt Hours" (the DEV-FIXTURES badge, on every page), a scene title
   visible before its dialog opened — and `help-otter`, whose click matched
   the shell's "O.T.T.E.R." (exact text beat Help's entry, whose text carries
   a subtitle) and measured the TOOL page under Help's name, digit for digit
   the `otter` row. Every proof must be false before its last step; the
   shell and the badge are excluded from proofs and clicks.
2. 🚨 **TAILWIND v4 COMPUTES ITS PALETTE AS `oklch()`, AND AN `rgb()` PARSER
   SEES NONE OF IT.** `bg-stone-800` → `oklch(0.268 0.007 34.298)`,
   `bg-black/50` → `oklab(0 0 0 / 0.5)`; only `@theme`'s hex and inline styles
   are `rgb()`. The first census skipped every palette colour in silence.
   Read colours through a 1x1 canvas; control it with a known pair (→
   `41,37,36`); reset `fillStyle` first, it IGNORES what it cannot parse.
   Tailwind v4's palette hexes are not v3's either (orange-400 `#ff8904`).
3. 🚨 **A CENSUS ROW THAT MATCHES ONE SPELLING IS BLIND TO THE OTHERS.**
   `border-2` read 0 while D.O.G.'s output panel drew its frame one side at a
   time; and a border set in a style object (`borderBottom: '2px …'`) was
   in no row at all — the CSS row reads hyphenated properties only. Both
   have rows now: 37 per-side utilities in 4 files, 101 inline 2px+ borders
   in 30 files. Censuses, not zeros: tab underlines and selected-row edges
   are 2px by design.
4. 🚨 **THE DECLARED FAMILY IS NOT THE DRAWN ONE.** Every element declares
   Geist; fontsource's subset has no `→`, so "Run Intake →" draws its arrow
   in Segoe UI. `getPlatformFontsForNode` reports the INTERNAL name, and an
   empty answer means either "not laid out yet" (wait for
   `document.fonts.ready` and two frames) or a FORM FIELD, whose text is in
   the browser's shadow DOM. A character scan misses `&rarr;` too.
5. 🚨 **A FLOOR THAT THE SHELL CLEARS BY ITSELF.** "Under 10 text nodes" could
   not trip: the shell and the badge are 18. Count outside the shell — and
   Files' own empty state is 4, so the floor is 3.
6. ⚠️ **`fits` CANNOT FAIL FOR A CAPPED PANEL.** Three dialogs are
   `maxHeight: 85vh` and measured exactly 595 tall at 700: they always fit
   because their body scrolls. V1 first reported that as news. `scrolls`
   says so now.
7. ⚠️ **A KNOWN LIST IS AN ALLOWLIST, AND ALLOWLISTS GROW.** Substring icon
   matching (`lucide-x` excused `lucide-x-circle`), no counts, and dialog
   screens inheriting the table underneath them: round one showed each.
   Exact icon, a count, the element names in React's warnings.
8. ⚠️ **TWO VITE SERVERS ON ONE ROOT SHARE `node_modules/.vite`.** Starting
   the second while the first was being measured forced a reload on the
   first: `/settings` measured 0 text nodes. Separately, Vite reloads a page
   the first time it meets a dependency it has not pre-bundled (a lazily
   loaded Budget view): the walk retries a screen once on "Execution context
   was destroyed".
9. ⚠️ **WCAG EXEMPTS DISABLED CONTROLS, NOT TRANSLUCENT ONES**, and a
   transparent border is not a border (every inactive R.A.B.B.I.T. tab
   reserves `2px solid transparent`). Both inflated or deflated the census
   until round one.
10. ⚠️ **`hOverflow` IS DOCUMENT-LEVEL, AND A WRAPPED CELL IS NOT A CLIPPED
    ONE.** Rate Card overflows inside a scroll container; Tasks' dates break
    mid-token. Neither moved `hOverflow` or `clipped`.
11. ⚠️ **`grep $'\r'` IN GIT BASH IS NOT A CRLF DETECTOR** (it listed 22 LF
    files as CRLF and found nothing in a real one), and **Python on Windows
    writes CRLF by default** (`newline=''`, or three `.mjs` came out CRLF —
    T3's trap 1 by a new road). Count bytes: `tr -cd '\r' < f | wc -c`.
12. ⚠️ **HEREDOCS AND `node -e` EAT BACKSLASHES HERE** — five times, each in a
    regex. Use the Write/Edit tools for code (T1 trap 17).
13. 🚨 **ROUND TWO BROKE SIX OF ROUND ONE'S INSTRUMENT FIXES** — the lane's
    pattern, again. The four worth carrying: React warns about a
    `<button>` inside a `<button>` ONCE per tag pair per page load, so an
    excused warning cannot tell a new nesting from the filed one (count
    them in the DOM); an OPAQUE modal covering 76% of the window was taken
    for the backdrop and its left column for the panel (a backdrop is
    translucent, never opaque); multiplying opacity into the ink alone made
    an opacity-0 nav column read "1.00:1 orange on orange" on every screen;
    and a rule that checks tracking only when it is PRESENT lets a Label that
    lost its +0.06em pass. Also: polling for a target to CLICK is not
    polling for the click to WORK (`@proj` now waits for "Control Panel" or
    "Switch"), and a `<select>` has no text node for any census to find.
    The fixes' own first strict run then flagged the kit's Stat numerals at
    20px as H1s missing their tracking: H1 is a role (`<h1>`), not a size.
14. 📌 **A GLOBAL CSS RULE REACHES THE UNTOUCHABLES.** `strong, b` in
    `@layer base` looked harmless and reached C4's preview and the operator
    console. Fix at the site.
15. 📌 **A CENSUS IS NOT A GATE — EXCEPT FOR A HARD CONSTRAINT.** The
