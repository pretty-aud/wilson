## 5. Traps hit

1. 🚨 **B4c TRAP 6 AGAIN, IN THREE BUDGET HOOKS.** A mounted guard set only by
   `useRef(true)` is false for ever after StrictMode's rehearsal unmount:
   Talent said "Loading talent..." for ever and Expenses drew nothing, in
   dev only — and the first "before" walk measured the loader. Fixed first
   (`1349cfa`), then the before re-walked. Grep any hook a view uses for
   `useEffect(() => () => { mountedRef.current = false }` before trusting a
   walk.
2. ⚠️ **`renderHook(…, { wrapper: StrictMode })` DOES NOT DOUBLE-RUN
   EFFECTS; `{ reactStrictMode: true }` does.** The first test of the hook
   fix passed without the fix.
3. ⚠️ **THE PRINT WINDOW IS ITS OPENER'S ORIGIN; A TEST PAGE IS NOT.**
   `window.open('')` from the app shares its origin, so the app's font files
   load. Playwright's `setContent` on a fresh page is `about:blank` with its
   own origin: every font load errored and the capture drew a fallback.
   Navigate the capture page to the app's origin first:
   `node scripts/ui-print-estimate.mjs <port> <outPrefix>` stubs
   `window.open`, clicks "Print / export", saves the HTML, renders it there
   and prints each face's load status.
4. ⚠️ **jsdom's CSSOM drops an `@font-face` rule's `src` and
   `unicode-range`** (only `font-family` survives): `appFontFaces` is tested
   with a fake document shaped as Chromium presents one.
5. 📌 `ui-audit.mjs` counts `font-size: calc(1em * var(--mono-size-adjust))`
   as off the scale: a figure that inherits its size must not write one.
6. 📌 A lane's ROOT class needs the dash form: `.rb-client` and `.rb-inv`
   fail `strayClasses`; `.rb-client-tab`, `.rb-inv-field` pass.
7. 📌 `.rb-x.ui-tabs` (0,2,0) TIES the kit's `.ui-toolbar .ui-tabs`: one
   class heavier (`kitFights` names it).
8. 📌 The guard's palette-leak CONTROL needed a literal lane class; a file
   whose only one is in a `${className}` template (CurrencyDisplay) needs the
   control to find either form (fixed in the guard).
9. 📌 **ViewTabs shows "Budget" with NO project open**: a script that sees
   it has not opened Salt Hours. Open it from Summary's project list (the
   walk's `@proj`).
10. 🚨 **PIPE THE CI API INTO A FILE, THEN PARSE.** `curl … | node -e` read
    an empty body once and spent one of the three anonymous reads; the
    status check spent another.
11. ⚠️ B4c trap 10, paid twice: once a file is in your context, a SHELL edit
    makes the harness re-send it whole (a 3,000-line file each time). Edit it
    with the Edit tool.
12. 📌 The pane's screenshot timed out on this machine all session; the walk's
    `--shots` and two Playwright drivers did the looking:
    `scripts/ui-shot-scrolled.mjs` (a screen scrolled to a text — Summary's
