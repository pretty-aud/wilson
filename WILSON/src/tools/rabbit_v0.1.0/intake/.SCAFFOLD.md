# RABBIT intake pipeline — Session 1 scaffold marker

Session 2 populates this directory with:

- `pipeline.js` — orchestrator: doc → chunks → parallel Claude calls → reducer → breakdown
- `personas.js` — system block fragments for film/tv, game, agency, experiential
- `reducers.js` — merge partial chunk outputs into a single project breakdown

And under `chunkers/`, one chunker per `document_kind`:

- `script.js` (scene-based)
- `treatment.js` (paragraph-based)
- `gdd.js` (section-based, long-context tolerant)
- `deck.js` (slide-based)
- `outline.js` (beat-based)
- `notes.js` (list/heading-based; Haiku model)
- `brief.js` (bullet-based)
- `pitchBible.js` (chapter-based)
- `lookbook.js` (image + caption pairs)

Claude models:
- `claude-sonnet-4-20250514` — creative docs (scripts, treatments, GDDs, briefs, decks, outlines, pitch bibles, lookbooks)
- `claude-haiku-4-5-20251001` — tabular / note-style docs
